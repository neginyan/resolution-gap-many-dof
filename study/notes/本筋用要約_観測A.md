# 本筋用要約 — 観測研究 段階A:非線形の流れで「臨界の速さ R」は何で決まるか

(ニューラルネットなし・厳密計算のみ。全数値はコードで確認済み:verification/run_all.py 29/29 PASS)

## 設定(一行で)
Y = X + N(ぼかし幅 σ)。dS/dt = r σ² tr F + Σ、R = −Σ/(σ² tr F)。r ≥ R ならエントロピーは減らない。
振り子(κ = 1)で、一つのガウスを不安定点 q = π から安定点 q = 0 まで 11 か所に置き、形を変え、σ = 0.01〜2(対数 25 点)で R を厳密に計算し、候補 (a)〜(d)(+追加の (e))と比べた。

## 分かったこと

### 1. 一つの山(単一ガウス)では、R は一つの式で完全に決まる
Stein の補題から、発散ゼロの流れでは厳密に

> **R = tr(F · Sym J̄) / tr F**、 F = (S + σ²I)⁻¹、 J̄ = E_ρ[Df](データの上で平均したヤコビ行列)

- 67 状態 × 25 σ = 1675 ケースで、数値積分の R とこの式の差は最大 4.3×10⁻¹²。四次の振動子でも 1.9×10⁻¹¹ で一致。
- 話し言葉で言うと:
  - 流れの曲がりは「山の上で平均した引き伸ばし」(J̄)という形でしか効かない。
  - ぼかしは「目に映る分布の細長さ」(F)を通じてしか効かない。
  - ぼかしが大きいと、目に映る形が丸くなる。引き伸ばしと縮みが打ち消し合い、R → 0。
- 帰結:R ≤ λmax(Sym J̄) ≤ κ。**単一ガウスの状態では予想1が成り立つ**(1675 ケースすべてで R ≤ λmax(Sym J̄) ≤ 1 を確認)。
  - 注意:この式は arrow-of-time 論文のリポジトリにはない。より広い文献で新しいかどうかは**まだ調べていない**。

### 2. 位置は形から切り離せる(45° の形)
- 引き伸ばし方向に s₁ = 0.05、縮み方向に s₂ = 0.5 の山では R/(c) = (s₁² + s₂²)/(s₁² + s₂² + 2σ²)。
- 11 か所すべてが一本の曲線に重なる(差は最大 4.1×10⁻¹¹)。
- 「どこに置くか」は c の大きさだけを決め、「σ でどう落ちるか」は形だけで決まる。

### 3. 対称性
- 運動量を反転しても変わらない状態(等方的な山、q 方向に細長く p 平均 0)では R = 0 ちょうど(最大 5×10⁻¹⁴)。
- p について鏡映すると R の符号が反転する(差は最大 6×10⁻¹⁵)。

### 4. 候補との比較(図 stageA_single.png)
| 候補 | 合うところ | 外れるところ |
|---|---|---|
| (a) 大域 κ = 1 | 上限としては正しい | 値は追わない。q₀ = π でも σ = 2 で R = 0.029 |
| (b) 中心の局所引き伸ばし | ほぼない | 形も σ も無視するため。q₀ = π で b = 1 なのに R(0.01) = 0.949 |
| (c) 定理9 の量 | **小さい σ で一致**:R(0.01)/c = 0.9992(全位置)。ずれは σ² に比例(比 1.0004 で確認) | σ が山の幅に近づくと離れる。q₀ = π で σ = 0.342 だと R = 0.493、c = 0.950 |
| (d) 窓で平均した引き伸ばし | 小さい σ でおおよそ(0.969 vs 0.949) | **逆向きに動く**:σ が大きいと 0.5 に近づくが、R → 0。q₀ = π、σ = 2 で d = 0.564、R = 0.029 |
| (e) ぼかし後のスコアで重みづけ(追加) | 線形の流れでは厳密。非線形でもかなり近い | 厳密ではない:q₀ = π、σ = 2 で +5.8%。q₀ = 0、σ = 2 では R = +0.0009、e = −0.0008 と符号まで違う |

→ 予想どおり、小さい σ では (c) と一致した。大きい σ で R が下がる理由は (d) のような「窓の中の引き伸ばし」ではない。「目に映る分布が丸くなること」(F の等方化)である。

### 5. 二つの山(混合)ではきれいな式が崩れる
- ランダムな 250 状態 × 4 σ = 1000 ケースで、R の最大は 0.771、すべて R ≤ 1(予想1に反する例はない)。
- 山同士が重ならないとき:成分ごとに式1を当てた R_sep で説明できる(重なり < 10⁻³ で中央値 4×10⁻¹¹ の差)。
- 重なると外れる:重なり ≥ 0.3 で差は最大 0.27。
- 自然な候補 λ_ρ = λmax(Sym E_ρ Df) を R が超える例:ランダムなもののうち 11 ケース。
- 「各成分の平均引き伸ばしの最大」λ_comp もランダムなものでは超えられなかった。しかし敵対的探索で**反例**が見つかった。
  - σ = 0.1 で R = 0.3488 > λ_comp = 0.3372(比 1.035)。λ_ρ = 0.270。
  - 大きく重なった(0.63)細長い二つの山。解像度を 1.5 倍にしても 10⁻¹³ まで同じ値。
  - つまり「混ぜると、どの成分単独よりも R が大きくなりうる」。
- (e) は混合でもよい近似になる:重なりのある 91 ケースで |R − e| の中央値は 0.004。|R − R_sep| の中央値 0.030 よりずっと小さい。
  - ただし上限にはならない(200 ケース中 94 で R > e)。反例の状態では e = 0.3515。
- 全観測を通じた R の最大は 0.949(< κ = 1)。

### 6. 予想1の言い換え(観測から言える範囲)
- 厳密に R = E[s·(f_eff − f)(Y)] / (σ² E|s|²)。
- e ≤ κ は常に成り立つ。したがって**予想1は「余り R − e が κ − e を超えない」ことと同じ**。
- 余りは、窓の中での流れの曲がり(二階微分)から来る。線形ならゼロ。

## まだ分からないこと
1. **重なった山で R を決める量**。R_sep も λ_comp も外れる。(e) は近いが、なぜ近いのか、どこまで近いのかは分からない。
2. **予想1そのもの**。反例はないが、混合での証明の筋はない。単一ガウスの証明は混合に直接は伸びない(λ_comp を超える例があるため)。
3. **余り R − e の大きさ**。曲がり × 窓幅で抑えられるのか。符号に決まりがあるのか(現状は半々で、ない)。
4. 振り子以外(曲がりの形が違う流れ、3次元以上)で同じ構図が成り立つか。四次の振動子では式1だけ確認した。
5. 式1(単一ガウスの法則)が文献上新しいか。

## 推測(観測が支える範囲に限る)
- 単一の山では、σ → ∞ で R → 0(式1から言える定理)。今回測った 67 状態では、σ を増やすと |R| は小さくなる一方だった。ただし一般の形で単調かは証明していない。
- 余り R − e は小さい(重なりのある混合で中央値 0.004、最大 0.063)。予想1が破れるとすれば、e が κ に近い状態で余りが正の場合である。そういう状態は見つかっていない(混合での e の最大は 0.663)。
- 反例は「大きく重なった二つの細長い山」だった。この形が λ_comp を超える鍵かどうかは、1 例なのでまだ言えない(次の測定1で確かめる)。

## 次に測るもの(提案)
1. 二成分の状態で、間隔 δ・傾き・重なりを一つずつ動かし、R を δ/σ の関数として描く(反例の仕組みを分解する)。
2. 余り R − e を、局所の曲がり(cos q の二階微分)× 窓幅² に対してプロットする。
3. 目的を「R の最大化」と「R − e の最大化」にした、より強い敵対的探索(3〜4 成分、σ を広く)。
4. 四次の振動子・二重井戸で、段階Aと同じ一式を回す。
5. 式1の文献調査(Stein の補題 × エントロピー生成 × ぼかし)。
