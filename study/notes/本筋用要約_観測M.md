- **「伸びる方向に細く構え、ほかの位置の方向には √σ 程度に長く構え、運動量だけの方向にはいくらでも長く構える。これが最良の目の形で、どの初期値から探しても、そこにたどり着く。」**

  - S の固有値が 0 から 10⁸、σ = 10⁻⁷ でも精度を保つ。

### Hénon–Heiles 系について(予言しなかった理由)
- V'' = [[1 + 2y, 2x], [2x, 1 − 2y]] なので、M = (I − V'')/2 = [[−y, −x], [−x, y]]。固有値は ±√(x² + y²)。
- 伸びは原点から離れるほど際限なく大きい(κ = ∞)。鞍点 (0, 1)、(±√3/2, −1/2) では λ_max = 1 だが、そこは伸びの山頂ではない(伸びの勾配がゼロでない)。
- 式は「伸びの 2 次の山頂」を前提にしているので、当てはまらない。
- エネルギーで領域を区切れば境界で最大になるが、そこでは伸びが 1 次で減る。そのため、ギャップは σ に比例しない別のべき(推定:σ^{2/3} 型)になると考えられる。今回は計算していない。

## 3. M3:多自由度で、混合がガウスを上回る割合

### 設定
- 連成振り子 ε = 0.1、0.3、σ = 10⁻³。各成分の p⁻ 方向は無限に長い。
- **3 次元への縮約(厳密):**
  - p⁻ が独立で一様なら、スコアに p⁻ 成分はなく、E[f·Q⁻|Y] = Y_p⁻ は E[s·E[f|Y]] から落ちる。
  - 残るのは (V⁺, W⁺, q⁻) の 3 次元の問題。
  - 単一ガウスで、4 次元の法則 1 と相対 4×10⁻⁸ で一致した。
- 評価器は 3 次元格子(各成分の事後期待値は閉じた形)。格子の収束は、per_sd 5 と 7 の比較で 3×10⁻¹⁰ 以内。
- **出発点:**
  - 段階H の 1 自由度の最良(8 成分の針の束)のうち重い K 成分を、V⁺–W⁺ 面に置いた。
  - 各成分に、ガウス最適の q⁻ 方向の広がりを与えた。
  - そこから全パラメータを山登り(1500 歩)+ Nelder–Mead で動かした。
- 1 自由度の振り子でも、**同じ手順・同じ手間**で比べた。

### 結果

| | K = 2 | K = 4 |
|---|---|---|
| 1 自由度(振り子) | 0.9795 | 0.9783 |
| 連成 ε = 0.1 | 0.9884 | 0.9876 |

(値は (κ − R)/(κ − R*_Gauss)。R*_Gauss は、M1 の自由最適化の σ = 10⁻³ での最良値)

- **得(1 − 比)は、1 自由度の約半分**(ε = 0.1 で 57%、ε = 0.3 で 44%)。
- 比べる目安として「得は V⁺–W⁺ 面の中だけで生まれ、係数のうち面が占める割合だけ薄まる」と考えると、面の割合(対角項の比)は ε = 0.1 で 0.77、ε = 0.3 で 0.70。

  - 実際は 0.988 と 0.990 で、それより得が小さかった。
- **見方の判定:**
  - 「混合の得は面の中だけで決まる」:方向は支持する(位置のほかの方向の分は薄めるだけで、ε が大きいほど得が小さい)。
  - 「1 自由度と同じ割合」:**否定**。
  - 薄まり方が面の割合より強い理由は、まだ分からない。考えられるのは二つ。(1) 3 次元では探索が浅い。(2) 面の中の混合が、q⁻ 方向の代償を少し増やす。
- **重かったもの:**
  - 3 次元格子(6×10⁴〜6×10⁵ 点)× K 成分の評価が、1 回 0.1〜0.5 秒。それを 1 つの探索で約 4500 回。
  - K = 8(80 パラメータ、1 回約 1 秒)は、1 つの探索に 2〜3 時間かかるので行っていない。
  - 1 自由度でも、同じ手間では K = 4 で 0.978 までしか下がらない(段階L の長い探索では 0.92)。だから、ここでの比較は「同じ手間での比較」であって、inf どうしの比較ではない。

## 4. M4:一様なギャップの二択(一歩進めた)

### 測ったこと(317 状態;σ ≤ 10⁻² の 295 状態で集計)
- **ρ と、ピントの重心の広がり d**(d = √(E[w u²]/(jσ))、√σ 単位)、**法則項の不足 (κ − λ_ρ)/σ**:
  - ρ > 0.25 の状態(28 個)は、d ≥ 1.76、法則項の不足 ≥ 0.47、ギャップ ≥ 0.916。
  - ρ > 0.3(2 個):ギャップ ≥ 1.92。
  - ρ > 0.5(1 個):d = 13.9、ギャップ 1105。
  - 最適に近い状態(ギャップ ≤ 1.2σ、d は 1.66〜2.40)では、ρ と d の順位相関は **−0.48**。ρ が大きい状態ほど、ピントは山頂の近くに集まっている(扇が要にピントを寄せる仕組みそのもの)。ρ と法則項の不足の順位相関は +0.25 と弱い。
  - なので、「ρ が大きい ⟹ d が大きい ⟹ ギャップが大きい」という単純な二択は、最適に近い状態では逆向きで、閉じない。
- **新しく分かったこと:状態別の連鎖の「Cramér–Rao の手前」は、ほぼ等式だった。**
  - 段階J の連鎖のうち、恒等式 + sin の不等式 + H_vv の正負への分解までの部分(Z の形)を計算した:
    1 − f ≥ (E[gw]/σ² − N + κ₂ J_ww)/J_tot、E[gw] ≥ Z/8 − corr(Z = E[w u²])
  - これは、全状態で実際のギャップの 0.9885 倍以上、中央値では 0.99999995 倍だった。
  - **損はすべて、そのあとの重みつき Cramér–Rao の一歩(Z を Θ′ で下から押さえる所)で出ている。**
- **二つの変数で書く:**
  - y = σ²J_ww/j(ピントに対する W 方向の情報)と d を使うと、ギャップ/σ ≈ (d²/8 + κ₂ y/σ)/(1 + y) − (小さな補正)。中央値で実際との比は 0.99987。
  - κ₂ ≈ 2 なので、AM-GM で **ギャップ/σ ≳ √P、P = d²·(y/σ)**。
  - 重みつき Cramér–Rao は P ≥ Θ′²(全状態で確かめた。最小の比は 1.0000007)。
- **観測:全状態で P ≥ 0.858。**
  - 最小は段階L の最悪状態(K = 24、ギャップ 0.918)。√P = 0.926。
  - 単一の線分では P ≈ 1。扇や針の束が P を少し下げる。
  - P の小さい状態ほどギャップも小さい(最適に近い状態で順位相関 +0.89)。図 stageM_dichotomy の左を見ると、最悪の状態は双曲線 d²y/σ ≈ 0.86 の上に並んでいる。

### 「ρ > 1/2 ならギャップ ≥ c₂σ」に使える不等式の候補(候補。証明はしていない)
1. **不確定性の形(本命):**
   - **E[w u²] · J_ww ≥ P₀ · E[w]²**
   - 言葉で言うと、「V 方向のピントの重みで測った、山頂からの距離の 2 乗平均」と「W 方向のフィッシャー情報」の積は、下から押さえられる。
   - これが一つ示されれば、ρ の場合分けはいらず、c = √P₀(主要次数)が出る。
   - 重みつき Cramér–Rao は、P₀ を (Λ/j)² で置いた特別な場合。Λ に焦点の傾きが入るので弱かった。
   - 重み w は「事後分布の V 方向の分散 = σ²(1 − w)」で決まる量なので、事後分布の 2 次モーメントだけで書ける。3 次キュムラントは要らない。この点で、段階L の「見込みが薄い」道より有望だと考える。
2. **二択の形:**
   - ρ ≤ 1/2 なら、Θ′ ≥ geo/2 で P ≥ geo²/4。
   - ρ > 1/2 なら、d ≥ d₂ または y/σ ≥ y₂ を示す。そうすれば Z の形から、ギャップ ≥ d₂²/8 または ≥ 2y₂。
   - データでは、ρ > 0.5 の状態は d = 13.9 なので、前者が成り立つ。ただし該当は 1 個だけで、しかも最適に近い状態では ρ と d が逆相関なので、この二択は弱い。候補 1 の方が筋がよい。
- 判定:**「方針がある」**(候補 1 が具体的になった)。証明はまだない。

## 5. M5(一部):曲げた針の連続の極限 — 段階L の問題が解けた
- 片の数 n = 128 で、段階L の n = 64 最適から形を最適化し直した(Nelder–Mead 250 反復、σ = 10⁻³)。
  - 結果は **0.50333**(n = 128)。曲率 −0.712(回転の速さ 1/√2 = 0.707 にほぼ一致)。
  - 同じ形を n = 256 で評価すると 0.5092 に上がる(段階L で見た上がり方)。
- **何が起きていたか:** 最適化し直すと、片の長さの係数 c_len が 1.18 → 6.8 に増えた。片 1 本の長さ(s.d. = c_len × 間隔)は **13.8σ(0.44√σ)** で、段階I の n = 24 の最適とほぼ同じ絶対長さになっている。
  - つまり最適な「曲げた針」は、細い曲線ではない。**弧に接する長さ約 0.44√σ のまっすぐな針を、連続的に並べたもの(接線の束)**である。
  - 段階L の「n を増やすと上がる」は、片の長さを間隔に比例させて縮めていたため、つまり接線の束を細い曲線に変えていたために起きていた。
- **連続の極限の確認:** 片の絶対長さを固定して n を増やした。

| n | 64 | 128 | 256 | n → ∞(1/n で外挿) |
|---|---|---|---|---|
| ギャップ/σ | 0.50315 | 0.50333 | 0.50342 | **0.5035** |

  - 1/n で収束した(差が半分ずつになる)。σ = 10⁻⁴ でも 0.5041 で、スケール不変である。
- **結論(数値の観察):** 回転についていく「接線の束」の連続極限は **0.5035σ** で、予言 1/2(β_eff = 1/8)と 0.7% で一致する。
  - なめらかな細い曲線は、それより悪い(384 片で 0.534〜0.569、まだ上がっている)。
  - 論文 B v1.1 の訂正「曲げた針は多角形」は正しいままだが、さらに言える。最適なのは、決まった長さ(≈ 0.44√σ)の接線を連続に並べた構造で、その値は 1/2 に近い。
  - 片の長さが √σ に比例する理由は、まだ導いていない(推定:長さ √σ の範囲で回転による角度のずれが σ 程度になり、ちょうど解像度でぼける大きさになるため)。
- 行っていないもの:自由な混合の K = 32 の磨きと、σ = 10⁻² の K = 24 の磨き。

## 誤り・言い過ぎ・前段階との食い違い
