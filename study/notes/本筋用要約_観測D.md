## 1. 流れの座標で書き直した予想1

ご提案の式変形は、振り子(0 ≤ ā ≤ 1)で厳密に正しい。

> 予想1 ⟺ M = E[(1 − ā)H_vv] + E[(1 + ā)H_ww] − D·tr F ≥ 0、 しかも M / tr F = 1 − R

数値での確認:全 1536 状態で、M/tr F と 1 − R の差は 2×10⁻¹¹ 以下。

**分かったこと**
- **二つの部分 P_v = E[(1−ā)H_vv]/tr F と P_w = E[(1+ā)H_ww]/tr F は、どの状態でも負にならなかった**(最小 0.0027 と 0.0079)。
- 各点で見ると負の寄与はある(P_v 側で最大 −0.166、P_w 側で最大 −0.300)。その大きさは、その方向の谷間(H_vv < 0 の質量、H_ww < 0 の質量)と強く連動した(順位相関 0.98 と 0.91)。それでも、全体の和は正のまま残った。
- **D は M を減らす向きに働くことがある**(D > 0 の状態が 580、最大 0.068)。
- **κ に一番近い状態(R = 0.9462)では、余りがきれいに半分ずつだった。** M/tr F = 0.0538 = P_v 0.0275 + P_w 0.0264 − D 0.0000。谷間は v 方向 0.035、w 方向 0.040 で、負の寄与はわずか(−0.0017 と −0.0004)。
- 話し言葉の絵:**「引き伸ばし方向のピントが鋭すぎる分」(P_v)と「縮み方向のピントが残っている分」(P_w)の両方が、R を κ の手前で止めている。** 山頂に近い状態では、両方が同じくらい小さくなる。
- 四次・二重井戸(κ = ∞)では、κ の代わりに「状態が見る局所の最大引き伸ばし κ_loc」を置いた。816 状態すべてで R ≤ κ_loc(余りの最小 0.139)。

## 2. 締めた上限 B′ = E[|ā|·(tr|H| − 2(H_ww)₊)] / E[tr H]

**式での確認**
- 振り子(ā ≥ 0)では、各点で ā(H_vv − H_ww) ≤ ā(tr|H| − 2(H_ww)₊) が成り立つ。
  - H_ww ≥ 0 の点:右辺 − 左辺 = ā(tr|H| − tr H) ≥ 0。
  - H_ww < 0 の点:|H_vv| + |H_ww| ≤ tr|H|(対角成分の絶対値の和は、固有値の絶対値の和以下)を使う。
  - したがって f ≤ B′ は厳密。ランダムな対称行列 20000 個でも確かめた。
- **谷間がない点では、B′ の中身は f の中身と一致する。** 谷間のない 261 状態では B′ = f(差 2×10⁻¹²)。B′ と f のずれは、谷間からだけ来る。
- **ā < 0 になりうる流れでは、B′ は上限にならない。**
  - 反例:ā = −0.5、H_vv = 1、H_ww = 5 で、局所の f = +2.0 > 局所の B′ = −2.0。
  - 実際の四次・二重井戸の状態でも、725 状態で点ごとに破れ、318 状態で f > B′ になった。
  - ā < 0 の点では W の代わりに V を使う修正版 B′_gen は、全状態で成り立った。

**数値**
- **B > 1 だった 21 状態のうち、20 状態で B′ ≤ 1 になった。**
- B′ > 1 で残ったのは、R = 0.946 の状態ただ一つ(B′ = 1.0067、B′ + D = 1.0068)。
  - この状態では、谷間(質量 0.150)が B′ を f より 0.061 押し上げている。
  - **予想1を B′ で保証できないのは、この一状態だけ**(1536 状態中)。

## 3. 山頂の近くを狙った探索(図 stageD_peak)

**(a) ご指定の σ(0.03, 0.1, 0.3, 1)で、距離 < 0.3 の状態を探した。**
- 余裕を使った割合の最大は 0.403(K = 3、σ = 0.03)。
- σ = 1 では、距離 < 0.3 の状態が一つも見つからなかった。
- 理由:振り子では、W 方向に細長くすると q 方向にも広がって引き伸ばしが下がる。単一の山の手計算では、到達できる距離の最小がほぼ σ になる。

**(b) 距離 0.3 → 0.001 の掃引(σ も探索の変数)**
- ランダムな出発点では、距離 ≤ 0.01 に届かなかった(9 探索)。
- そこで「W 方向に細長い、π 上の山」を出発点にした探索を追加し、最小で距離 0.0004 まで到達した。

- **log(超過分の最大) 対 log(距離) の傾きは 1.43**(全範囲)、**距離 ≤ 0.05 では 1.17**。どちらも ≥ 1 なので、ご提示の基準では予想1と整合する。
- **山頂に近いほど、余裕を使う割合は小さくなった。** 距離 ≤ 0.02 の 11 状態では最大 0.082。
- **注意が一つある。** 最後の 2 点(距離 0.0012 と 0.0004)の間だけ見ると、傾きは 0.27 と浅い。距離 0.0004 の点の割合 0.082 が、その一つ手前(0.037)より高い。
  - 探索で見つかった最大値は「本当の最大の下限」にすぎないので、ここが探索のばらつきなのか、本当の傾向なのかはまだ区別できない。
- **何が縮むか**
  - **引き伸ばしの散らばり Var(ā) は、距離のほぼ 2 乗で縮んだ**(傾き 2.35)。
  - **ピントのずれは、ほとんど縮まなかった**(傾き 0.23。0.15〜1.1 の範囲)。
  - 超過分 / (√Var(ā) × ピントのずれ) は、最良状態で 0.34〜0.69 にとどまった。
  - 話し言葉にすると:**山頂の近くでも「ピントのずれ」は残るが、それが掛け合わされる相手「引き伸ばしの場所ごとの差」が、距離に比例して消えていく。だから超過分は距離と同じかそれ以上の速さで小さくなる。**(推測:Cauchy–Schwarz 型の上限 |共分散項| ≤ √Var(ā) × (ピントのずれの大きさ) が働いていると見られる。式としてはまだ詰めていない。)
- 掃引全体では、割合の最大 0.830 が出た(距離 0.288、σ = 0.0063、K = 3)。これまでの最大 0.714 を超えた値で、山頂から遠めの状態での値。

## まだ分からないこと
1. **予想1は開いたまま。** ただし B′ で保証できない状態は、見つかった中では R = 0.946 の一つだけになった。
2. **P_v と P_w が必ず正であることの証明。** 各点では負になりうるので、平均を取った後でなぜ正に残るのか(谷間の負の寄与が、どこかの正の寄与で必ず補われる仕組み)が分からない。
3. **距離 0.001 付近の傾き。** 最後の 2 点で傾きが浅くなったのが、探索のばらつきか本物か。
4. 割合 0.830 の状態(距離 0.29)で、さらに 1 に近づけられるか。

## 推測(観測が支える範囲に限る)
- 山頂近くでは、超過分 ≈ (0.3〜0.7) × √Var(ā) × (ピントのずれ) で、Var(ā) ∝ 距離²。そのため超過分は距離の 1 乗より速く 0 に向かう。今回の 9 点はこの絵と合っている。
- 予想1が破れるとすれば、山頂のすぐ近くではなく、中くらいの距離(0.1〜0.3)の状態である可能性が高い(割合 0.830 の状態は距離 0.29、R = 0.946 の状態は距離 0.11 で谷間を持つ)。

## 次に測るもの(提案)
1. **距離 0.0003〜0.003 だけを密に、出発点を増やして再探索する。** 最後の 2 点の浅い傾きが本物かを決める。
2. **割合 0.830 の状態と R = 0.946 の状態を出発点に、割合そのものを最大化する局所探索。** 中距離で 1 に近づけるかを見る。
3. **|共分散項| ≤ √Var(ā)·√E[(2(H_qp − F_qp)/tr F)²] の形の上限を、全状態で数値的に確かめる。** 証明の足場にする。
4. **P_v ≥ 0、P_w ≥ 0 を、谷間の質量と深さの関数として調べる。** 負の寄与がどこまで大きくなれるかを測る。
