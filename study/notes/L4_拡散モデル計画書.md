# 課題 L4:拡散モデルでのデモ — 計画書(設計のみ、未実装)

## 目的
- 振り子の流れ(非線形)を前向き過程に使う「位相空間の拡散モデル」を作る。
- 学習したスコアから、粗視化エントロピーの増減を測る。
  - 臨界の速さ R
  - 論文 B の予言「R ≤ κ − cσ」(σ に比例した余裕)
- 論文 B の結果を、機械学習の言葉で見える形にする。

## 0. 二つの「境目」を混同しない(最重要)

| | (I) 逆向き SDE が作れるか | (II) 粗視化エントロピーが増え続けるか |
|---|---|---|
| どんな条件か | 各点の条件 | 状態全体で積分した量 R = −Σ/(σ² tr F) と、粗視化の速さ r の比較 |
| σ への依存 | **しない**(非線形でも境目は κ のまま) | **する**(R ≤ κ − cσ。余裕は σ に比例) |
| 測り方 | 学習したスコアで逆向き過程を走らせ、壊れないかを見る(各点の診断) | 学習したスコアから tr F と Σ を推定し、R を出す(積分の診断) |

- 実験は (I) と (II) を別々の節に分ける。図も分ける。
- 「σ に比例した余裕」は (II) にだけ現れる、と本文で明記する。
- (I) の判定基準(各点の条件の正確な式)は、本筋の定義をそのまま使う。この計画書では新しく定義しない。

## 1. 設定(論文 B の設定に合わせる)
- **位相空間:** (q, p) の 2 次元。流れは f = (p, −sin q)。双曲点 (π, 0) で κ = 1。
- **前向き過程:** 論文 B の「流れ + 粗視化」をそのまま使う。
  - きれいな成分:X_t = Φ_t(X_0)。Φ_t は振り子の流れ(決定論的)。
  - 観測:Y_t = X_t + σ(t) Z。σ(t) = σ₀ e^{rt} で、r = σ̇/σ。
  - これは「ノイズの大きさが増える拡散モデル」で、ドリフトはきれいな成分にだけ働く。
- **注意:** dX = f(X)dt + √(2r) dB のような「力学にノイズを入れる」SDE は、別のモデルになる。論文の式 dS/dt = rσ² tr F + Σ が成り立つのは上の形の方なので、混同しない。
  - 実装前に、r の定義(σ̇/σ)と拡散係数の対応を式で確認する(2 倍の違いが出やすい)。
- **σ:** 0.03、0.1、0.3 の 3 通り。
- **初期分布:** 実験場で作った状態をそのまま使う。
  - 最良の単一ガウス(線分)
  - 段階I の扇
  - 段階L の最悪状態(K = 16、24 の混合)
  - 比較用:山頂から離れた広いガウス

## 2. 何を測るか
1. **tr F = E|s(Y)|²**:学習したスコア s_θ(y) から。
2. **Σ = −E[s(Y) · E[f(X)|Y]]**:E[f(X)|Y] は二通りで推定し、差を誤差に含める。
   - (a) 別のネットワークで (Y, f(X)) の組を回帰する(直接)
   - (b) 2 次の Tweedie を使う:E[X|y] = y + σ²s、Cov(X|y) = σ²I + σ⁴∇s から、E[f(X)|y] ≈ f(E[X|y]) + ½ tr(Cov ∇²f)
3. **R = −Σ/(σ² tr F)** と、余裕 (κ − R)/σ。次の三つと比べる。
   - 厳密なスコアでの値(t = 0 では i_tools.fields で厳密に出る)
   - 論文 B の状態別下界 Θ′σ/(1 + Θ′σ/2) − ε̃ − D
   - 単一ガウスの R*(σ)
4. **dS/dt の直接測定:** S(Y_t) を k 近傍法で推定し、時間差分をとる。予言 dS/dt = rσ² tr F + Σ と比べる(独立な確認)。
5. **(I) の診断:** 学習したスコアで逆向き過程を回す。終点の分布と元の分布の差(ワッサースタイン距離)が、r/κ の境目でどう変わるかを見る。σ を変えても境目が動かないことを確かめる。

## 3. 厳密なスコア(ガウス混合)で先に確かめられる部分
- **t = 0 の瞬間なら、すべて厳密に計算できる。** 初期分布がガウス混合なら、p_Y・スコア・E[f|Y] が閉じた形で出る(実験場のコード)。
- **先にやる手順:**
  - (i) 厳密なスコアで、推定の手順(サンプル平均・回帰・Tweedie)を検証する。
  - (ii) 厳密なスコアに人工的な誤差(相対 η のノイズや偏り)を足し、R がどれだけ動くかを測る。これで「どの精度のスコアなら結論が言えるか」を、学習の前に決める。
  - (iii) 学習したスコア(t = 0、σ 固定)と厳密なスコアを、同じ状態で直接比べる。これが学習誤差の一番きれいな測り方になる。
- t > 0 では分布はガウス混合でなくなるので、サンプルと学習に頼る。ただし小さな t では、t = 0 の厳密値と連続につながることで確かめられる。

## 4. 学習スコアの誤差が結論をどこまで揺らすか(見積もり)
- R は比なので、スコアの相対 L² 誤差 η に対して、R の誤差はおよそ (|R| + κ)·η 程度と見込む。これは見積もりなので、3 の (ii) で実測する。
- 余裕 cσ を見分けるには、η ≪ cσ/(|R| + κ) が要る。c ≈ 0.92(段階L の最悪状態)、κ = 1 として:

| σ | 余裕 cσ(最良ガウスの値) | 必要な η |
|---|---|---|
| 0.3 | 約 0.24 | 0.05 以下で十分 |
| 0.1 | 約 0.09 | 0.02 以下 |
| 0.03 | 約 0.03 | 0.005 以下(難しい) |

- **結論として主張するのは σ = 0.1〜0.3 に限る。** σ = 0.03 は「傾向の確認」にとどめる。
- 偏り対策:
  - スコア推定の系統誤差は、雑音除去スコアマッチングの重みに依存する。重みを変えて 2 通り学習し、R の差を誤差に含める。
  - E[f|Y] の推定は、(a) 直接回帰と (b) Tweedie の差を誤差に含める。
- (I) の境目は各点の条件なので、スコアの小さな誤差では動かない。誤差は「境目のぼやけ」として出る。

## 6. 成功の判定
- **(II):** σ = 0.1 と 0.3 で、学習スコアから出した (κ − R)/σ が、厳密値と誤差の範囲で一致する。さらに、dS/dt の直接測定と予言が一致する。
- **(I):** 逆向き過程の境目が、σ によらず r ≈ κ にある。
- **失敗の見分け方:** (II) の誤差が余裕より大きいときは、「σ に比例した余裕は、この精度の学習スコアでは見えない」と結論する。そのうえで、必要な精度を報告する。
