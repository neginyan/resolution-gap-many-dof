# 本筋用要約 — 観測研究 段階I:扇の連続極限/下限の足場/他の流れ

(厳密計算のみ。全数値はコードで確認済み:verification/run_all_I.py 29/29 PASS。以前の段階も再実行:A 29/29・B 34/34・C 25/25・C+ 20/20・D 23/23・E 23/23・F 19/19・G 27/27・H 23/23 PASS)

## 結論(先に)
1. **扇の連続極限では、g\* は約 0.048 で頭打ちになった。**
   - 角度ごとの重さ・長さ・太さ・ずれを関数として最適化した(17 変数)。g\* = 0.0478 で、線分の本数 20 → 80 でも変わらなかった。
   - 段階H の自由な 8 成分(0.053)のほうが少し上で、上限はおそらく 0.05 前後。
   - したがって振り子では、**1 − R ≥ 約 0.95σ が今のところの下限**である。
2. **下限の足場ができた。厳密な恒等式 + H ≤ I/σ² を一回だけ使う不等式で、状態ごとの下限を作れる。**
   - 単一ガウスでは等号に近い(下限/実際 ≥ 0.997)。
   - 全 290 状態で、下限 ≥ 0.767σ(実際の最小は 0.946σ)。
   - 緩むのは一か所だけ:**「V 方向のピントを、伸びの強い山頂近くにだけ寄せる」自由度**。これは扇や混合が得をする仕組みそのものである。
   - 全部の重みを使う場合(j = 1)は、W 方向の Cramér–Rao で単一ガウス並みの係数(≈ 1)が厳密に出る。
3. **他の流れでも、隙間は σ に比例した。係数は一つの式で決まる。**
   - 単一ガウス:**κ − R\* = 2√(2βκ)·σ + O(σ²)**。β は「山頂から縮む方向 W に動いたとき、伸び(V への射影)が二乗で減る係数」。
   - 4 つの流れすべてで、数値と式が 10⁻⁷ まで一致した。
   - 多項式の山頂(二重井戸、四次振動子)では、R\* は**完全に閉じた形(代数式)**になった。
4. **ねじれの流れでは、混合の得が大きい(約 40 %)。仕組みも分かった:針を曲げると、伸びる方角の回転についていける。**
   - 単一ガウス(まっすぐな針)の √3/2 = 0.866σ から、**曲げた針では 0.509σ**(予測 0.5σ)に下がる。
   - 最適な曲率は −0.709 で、伸びる方角が回る速さ 1/√2 = 0.7071 と一致した。
   - それでも隙間は σ に比例し、R < κ。

話し言葉の絵:
- **「山頂の引き伸ばしを見るには、細い針(V 方向にピント)を、縮む方向に少し長く伸ばす必要がある。」**
- **「針が長いほどピントの縦横比は良くなるが、端は山頂から外れる。その釣り合いで、余裕は窓の幅 σ に比例して残る。」**
- **「ねじれの流れでは、山頂の上でも伸びる方角が回っている。まっすぐな針は回る方角に合わせられないが、曲げた針は合わせられる。だから余裕が 4 割減る。それでも、山頂から外れることによる損は残るので、余裕は σ に比例する。」**

## 1. 扇の連続極限(図 stageI_fan)

### 作り方
- 山頂を通る線分の扇を考える。角度の変数 x ∈ [−1, 1] の関数として、次をチェビシェフ級数で表した:
  - 重さ(6 項)
  - 長さ(4 項)
  - 太さ(3 項)
  - V 方向のずれ(3 項)
  - 角度の幅 Θ
- 合計 17 変数を、σ = 10⁻³ で最適化した(適応的な乱択山登り 1500 歩 + Nelder–Mead)。

### 結果
| 出発点 | g\*(n = 40) |
|---|---|
| 段階H の対称な扇から | **+0.0478** |
| 広い、非対称な扇から | +0.0477 |
| 乱択 | −0.0001(単一の針に落ちた) |
| 乱択 2 本目 | 7 時間で終わらず、途中で止めた |

- **連続極限:** 本数 n = 20、40、80 で 0.04786、0.04784、0.04781。すでに連続の極限に達している。
- **スケール不変:** σ = 10⁻⁴ で 0.04782、σ = 10⁻² で 0.04706。
- **最良の扇の形:**
  - 重さは角度ゼロ(W 方向)のまわりに集中している(およそ ±0.5 × √σ/2 の範囲)。
  - 長さは、端の角度ほど長い(中央で 1.08 × 2√σ)。
  - 太さはほぼ 0。
- **比較:** 段階H の対称な扇は 0.044、自由な 8 成分は 0.053。関数で滑らかに表した扇は、自由な混合にわずかに届かなかった。**g\* の上限は 0.05 前後とみている。**

## 2. 下限 1 − R ≥ cσ の足場(図 stageI_bound)

記号:
- g(y) = 1 − ā(y):局所的に足りない伸び
- J = E[H]:フィッシャー情報
- j = σ² E[(H_vv)₊]:V 方向のピントが、上限 1/σ² にどれだけ近いか(1 で上限)

| 段階 | 内容 | 厳密さ |
|---|---|---|
| (E) 恒等式 | J_tot(1 − f) = E[g H_vv] − E[g H_ww] + 2J_ww | 厳密(全状態で 4×10⁻¹⁶) |
| (B) 寄せの上限 | H_vv ≤ 1/σ²(Tweedie)なので、E[g H_vv] ≥ Q(j)/σ²。Q(j) は、g の小さいところから質量 j 分だけ足した値 | 厳密。全状態で 下限 ≤ 1 − f |
| (CR) W 方向の Cramér–Rao | 各 W 線上で部分積分すると J_ww · E[(w + v)²] ≥ 1。よって Q(1)·J_ww ≥ (1 − λ_ρ)/(2(E δ² + σ²)) → 1/8 | 厳密。全状態で成立 |
| (U) 結合 | σ が小さいとき 下限 ≈ 2√(2Π)·σ、Π = Q(j)J_ww/j²。単一の線分では Π = 1/8 なので c = 1 | j = 1 なら (CR) で閉じる |

### 数値(σ ≤ 10⁻² の 268 状態)
- 実際の (1 − R)/σ の最小は **0.946**(段階H の 8 成分)。
- 状態ごとの厳密な下限の最小は **0.767σ**(山頂付近の状態)。
- 単一の線分では、下限/実際 = 1.000、0.9999、0.9996、0.997(σ = 10⁻³〜0.1)。
- 混合(扇・段階H)では j = 0.83〜0.88 で、下限/実際は約 0.85。
- 「遠くに広い山」を持つ状態では j = 0.02〜0.06 まで下がり、下限/実際は 0.33〜0.6 まで緩む。

### 分かったこと
- 鎖のうち、緩むのは (B) だけ。(B) が許しているのは「ピントを g の小さい場所に寄せる」ことで、それはまさに扇の仕組みである。
- 本当は、ピントの寄せ方には幾何的な制約がある。V 方向に鋭い場所は、W 方向にもある長さを持たねばならない。この制約を「重みつきの Cramér–Rao」として (B) に組み込めれば、c ≈ 0.95 に近い定数が出るはずである。**これが次の一手。**

## 3. 他の流れ(図 stageI_flows)

### 単一ガウスの R\*(σ)
- f = (p, g(q)) 型の流れでは、伸び a = (1 + g′)/2 で、式1は振り子と全く同じ形 R = λφ になる。最適は、やはり傾いた幅ゼロの線分である。
- 山頂が多項式 a = κ − bq² の場合、λ は S_qq の一次式になる。ε = σ√(b/κ) とおくと、**R\*/κ は ε だけの普遍関数**になる:
  1 − R\*/κ = Ψ(ε) = 2ε − (5/2)ε² + (7/4)ε³ − (1/8)ε⁴ − (53/64)ε⁵ + …(厳密な有理数係数)
- 最適な長さの級数 2 − 3ε + (9/4)ε² − (81/64)ε⁴ + … から、**v\* = √(4 + 9ε²) − 3ε** と読み取れた。これを入れると Ψ は 10⁻¹⁶ で一致し、**多項式の山頂では R\* が完全に閉じた形(代数式)になる。**
- ねじれの流れでは、式1を使った数値最適化を行った(中心の半径・二つの幅・傾き。乱択 3000 点でも超えられないことを確認)。

| 流れ | κ | β | 予測 2√(2βκ) | 数値(σ → 0 に外挿) | σ = 10⁻³ |
|---|---|---|---|---|---|
| 振り子 | 1 | 1/8 | 1 | 1.0000 | 0.9991 |
| 二重井戸 | 1 | 3/4 | √6 = 2.4495 | 2.4495 | 2.4457 |
| 四次振動子(q = 0 の局所山頂) | 1/2 | 3/4 | √3 = 1.7321 | 1.7321 | 1.7283 |
| ねじれ H = ½ ln(1 + q² + p²) | 1/4 | 3/8 | √3/2 = 0.8660 | 0.8660 | 0.8634 |

- 前回の途中経過では、ねじれの「数値(σ → 0)」を 0.863 と書いたが、それは σ = 10⁻³ の値だった。外挿すると 0.8660 で、予測と一致する。
- ねじれの β = 3/8 の内訳:
  - 半径のずれで伸びの大きさが減る分:1/8
  - 伸びる方角が回る分:1/4
- 式1と格子計算の一致:全部の流れで 4×10⁻¹² 以内。
- 注意:四次振動子は山頂から離れると |a| がいくらでも大きくなる(κ = ∞)。ここでの比較は「q = 0 の局所的な山頂の近く」に限っている。

### 混合
- 二重井戸・四次振動子:混合の得は小さい(g\* ≤ 0.02。短い探索)。振り子と同じ「扇」の程度である。
- **ねじれ:得が大きい。**
  - K = 2 で 0.21〜0.23。成分を一つずつ足すと、K = 8 で 0.39(隙間 0.525σ)。
  - σ = 10⁻⁴〜10⁻² で隙間/σ は同じ(0.526、0.525、0.519):スケール不変。
- **仕組みの確認(曲げた針):**
  - 線分を円弧状に並べた「曲がった針」を、6 変数で最適化した。
  - 最適な曲率は 4 つの出発点すべてで −0.709〜−0.714。伸びる方角が W 方向に沿って回る速さ 1/√2 = 0.7071 と一致した。
  - 隙間は **0.509σ**。回転の分を除いた β = 1/8 による予測 2√(2·(1/8)·(1/4)) = **0.5σ** にほぼ一致した。
  - g\* = 0.41 で、スケール不変(σ = 10⁻⁴ で 0.411)。
  - 閉じた形を使わない直接和でも確認した(差 1×10⁻⁸)。
  - 注意:線分を細かくしすぎると(96 本)、g\* が 0.39 にやや下がる。各線分の長さを間隔に比例させた作り方のためで、上限を決める話ではない。

### 一般則(推測を含む)
- κ − R ≈ 2√(2β_実効 κ)·σ という形になる。β_実効 は「針を曲げて、伸びる方角の回転についていった後に残る、伸びの大きさの減り方」である。
- 混合はそこから、さらに数 %(扇の効果)だけ得をする。
- 振り子・二重井戸・四次振動子では伸びる方角が一定なので、曲げる得はない。ねじれでは回転分(β の 2/3)が消える。

## 分かったこと/まだ分からないこと
**分かったこと**
- 振り子の扇:上限は約 0.05。隙間 ≥ 約 0.95σ。
- 下限の鎖:厳密な恒等式 + 一つの不等式で、全状態で ≥ 0.767σ。単一ガウスでは等号に近い。
- 単一ガウスの隙間の一般式 2√(2βκ)σ。多項式の山頂では R\* が閉じた形。
- ねじれでは、曲げた針が回転分の損を消し、隙間は 0.5σ になる。

**まだ分からないこと**
1. 下限の (B) を「重みつき Cramér–Rao」で締めて、c を 0.9 以上にすること。
2. ねじれで、曲げた針に扇の効果を足すとどこまで行くか(0.5σ より少し下がるはず)。
3. 曲げて回転に追従する効果を含めた β_実効 を、一般の流れについて式で定義すること。

## 次に測るもの(提案)
1. **重みつき Cramér–Rao:** ピントの寄せ方 h(y) = σ²H_vv(y) の W 方向の変化の速さを各状態で測る。その変化の速さで (B) を締めた下限を作り、0.946 にどこまで迫るかを見る。
2. **ねじれの「曲げた扇」:** 円弧の上に扇を載せて最適化し、隙間の下限を求める。
3. **β_実効 の一般式:** W の積分曲線に沿った、伸びの大きさの減り方として定義し、別の流れ(たとえば方角の回り方が場所で変わる流れ)で予測と照合する。
