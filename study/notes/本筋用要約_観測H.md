## 結論(先に)
1. **本当の R\*(σ) は、ほぼ閉じた形で求まった。**
   - 最良の単一ガウスは「幅ゼロの線分」で、山頂を通る。向きは W(縮む方向)から −V 側へ **角度 σ/4** だけ傾き、長さは約 2√σ。
   - 最適化は 1 変数の滑らかな問題にまで落ちる。
   - 段階G で 4 変数の数値最適化から出した R\* は、この本当の値と 4×10⁻¹⁴ で一致していた。**段階G の比較(1591 状態で R ≤ R\*)はそのまま正しい。**
2. **R ≤ R\*(σ) を破る状態が見つかった。予想1′ は成り立たない。**
   - 調べた 8 組(K = 2, 3、σ = 10⁻³〜0.3)すべてで、混合が R\* を上回った。g\* = (R − R\*)/(1 − R\*) は +0.010〜+0.030。
   - 長い探索では K = 4 で +0.043、成分を 8 まで増やすと **+0.053** になった。
   - 形は「**山頂で交わる、傾きの少しずつ違う細い線分の扇**」。
   - 3 種類の独立な計算で一致を確かめた(下の 2 節の「確認」の段)。
3. **それでも R < 1 = κ。** 余裕 1 − R は σ に比例したまま縮み、(1 − R)/σ ≥ 0.94 だった。**予想1(R ≤ κ)には反例は出ていない。**
   - 混合が得をするのは「最良の単一ガウスの余裕のうち数 %」まで。今のところ、余裕そのものを消す気配はない。
4. **余裕の σ 展開は、何次まででも厳密な有理数で出せる。** σ¹¹ まで計算した。
   1 − R\*(σ) = σ − (7/8)σ² + (65/96)σ³ − (61/128)σ⁴ + (3151/10240)σ⁵ − (8483/46080)σ⁶ + …

話し言葉の絵:
- **「一本の線分でピントを合わせると、線分の端の方まで同じようにピントが合ってしまう。でも引き伸ばしがいちばん強いのは山頂(交差点)だけ。」**
- **「線分を扇のように少しずつ角度を変えて重ねると、重なる交差点にだけピントが集まる。だから、一本の最良の線分より少しだけ得をする。」**
- **「それでも窓の幅 σ より細かくはピントを合わせられないので、余裕は σ に比例して残る。」**

## 1. 本当の R\*(σ)(図 stageH_rstar)

### 式の流れ
- 式1(単一ガウス、厳密)では R = λ·φ となる。
  - λ = (1 − cos q e^{−S_qq/2})/2:成分が感じる引き伸ばし
  - φ = (T_ww − T_vv)/(T_ww + T_vv):ピントの縦横比(T = S + σ²I)
- **φ は V/W の非対角成分 S_vw によらない。** 一方 S_qq = (S_vv + 2S_vw + S_ww)/2 は S_vw で変わる。
  - そこで S_vw = −√(S_vv S_ww)(幅ゼロ)にすると、q 方向の広がりが最小になり、λ が最大になる(W 方向に長い場合、φ > 0。R > 0 にはこれが必要)。
  - **最良は幅ゼロの線分である。**
  - 話し言葉では:「ピントの縦横比を変えずに、山頂からの q 方向のはみ出しだけを減らせる向きがある」。
- 中心は山頂 q = π。線分の V 成分 α と W 成分の差 d を、u = d²/σ、p = αd/σ² で表す。
  - 内側の最適は閉じた形:**p\* = 2/(1 + √(1 + 4σ/u))**
  - 残りは u についての 1 変数の最大化になる。
- σ が **σ_c = 0.93909** を超えると、有限の線分より「無限に長い線分」の極限(R → 1/2)が勝つ。σ ≥ σ_c では R\* = 1/2 で、達成されない。

**確認(3 種類の独立な計算)**
- いつもの評価器:格子を 4 通りに変えても 10⁻¹³ 以内で一致した。

- 閉じた形を一切使わない直接和の計算(事前分布を節点に分け、核関数とその微分を足し上げる。最初の版は細い方向の節点が足りず 5×10⁻³ ずれていたが、節点を増やして直した):σ = 0.1、0.3 の破れを 5×10⁻⁸ 以内で再現した(R − R\* = +2.3×10⁻³、+5.5×10⁻³)。

**スケール不変性**
- 見つけた形を σ = 10⁻⁵〜10⁻³ に縮めても、g\* はほぼ同じだった(差 < 2×10⁻³)。破れは「余裕の数 % 分」という形で、σ によらず残る。
- σ ≤ 10⁻⁶ では倍精度の桁が足りず、値が信頼できない(1 − R ~ 10⁻⁷ を 10⁻³ の相対精度で測る必要がある)。この範囲は使わなかった。

## 3. 余裕 1 − R\*(σ) の σ 展開
- 有理数の冪級数を記号的に解いて、**係数を σ¹¹ まで厳密に出した**(sympy が使えない環境なので、分数の冪級数を自作した)。
  1 − R\* = σ − 7/8 σ² + 65/96 σ³ − 61/128 σ⁴ + 3151/10240 σ⁵ − 8483/46080 σ⁶ + 2112989/20643840 σ⁷ − 36571/688128 σ⁸ + …
- 最適な線分の長さ:d²/σ = u\* = 4 − σ + (5/8)σ² − (1/12)σ³ + …
- 傾けない針の場合:1 − R = σ − 3/4 σ² + 11/24 σ³ − 1/4 σ⁴ + …。σ¹ の項は同じで、**傾きの効果は σ² の項から入る(−3/4 → −7/8)**。
- 打ち切り誤差は、次の項の大きさとぴったり一致した(σ = 0.01 で比 1 ± 0.05)。σ¹¹ までの和は、σ = 0.3 で誤差 1×10⁻⁹。
- 係数の比 |c_k/c_{k+1}| は 1.14 から 2.33 へ増え続けている。級数は σ ≈ 2 程度まで、たぶんそれより先まで収束する。
- 3 次まで(65/96、傾けない場合の 11/24)は手計算の展開とも一致した。
- **答え:閉じた形(有理数係数)は何次まででも出せる。** ただし、全部の次数をまとめた初等関数の形(閉じた和)は見つかっていない。最適条件に e^{−σu/4} が入るので、初等関数にはならないと考えている。

## 分かったこと/まだ分からないこと
**分かったこと(観測と式)**
- 本当の R\*(σ):幅ゼロで傾いた線分。1 変数の最大化と、厳密な級数。
- 予想1′(R ≤ R\*)は成り立たない。混合は余裕の 3〜5 % だけ得をする。
- その得は σ によらない(スケール不変)。余裕 1 − R は σ に比例して残る。

**まだ分からないこと**
1. **成分を増やしたときの g\* の上限。** K = 8 まで鈍く増え続けた(0.031 → 0.053)。一方、対称な扇は本数を増やしても 0.044 で頭打ちだった。これが 1 に届かない(1 − R ≥ cσ、c > 0)ことが、予想1を「σ に比例した余裕つき」で言うための鍵になる。
2. 扇の形の最適化:角度の分布と長さの分布を連続な関数として最適化したら、どこまで行くか。

## 推測(観測が支える範囲に限る)
- **予想1″:どの状態でも 1 − R ≥ c·σ(c は 0.9 前後の定数)。** 根拠:どの探索でも (1 − R)/σ ≥ 0.94。得の源は「交差点にピントを集める」ことで、窓 σ より細かくは集められない。
- 予想1(R ≤ κ)の証明の道筋は、「単一ガウスの法則(式1)+ 混合のピントの再配分の上限」と言い直せそうに見える。

## 次に測るもの(提案)
1. **扇の連続極限:** 角度の分布 ρ(θ) と長さ ℓ(θ) を関数として最適化する。K → ∞ で g\* がどこで頭打ちになるかを見る。
2. **扇の解析:** 要(山頂)でのピントの集中度と g\* の関係を式にする(共分散の項を、扇の角度分布で書く)。
3. **他の流れ(四次振動子、二重井戸)でも、混合が最良の単一ガウスを上回るか。**
