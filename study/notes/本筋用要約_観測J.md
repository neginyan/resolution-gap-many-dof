## 結論(先に)
1. **全状態で一様な定数 c は、式としては出せなかった。** ただし、一歩手前まで来た。
   - 状態ごとに成り立つ定理を一つ、厳密に作った:
     **κ − R ≥ Θ′σ/(1 + Θ′σ/2) − ε̃ − D**(振り子、κ = 1)
   - Θ′ は「V 方向のピントの重み」と「W 方向の情報」から作る、状態ごとの量。ε̃ と D は小さな補正。
   - 残る未証明の一歩は、**「Θ′ に状態によらない下限がある(と、ε̃ と D が o(σ) である)」こと**だけ。
   - 数値では、σ ≤ 10⁻² の全 268 状態で Θ′ ≥ 0.9125 だった。
2. **状態ごとの下限は大きく改善した。**
   - 段階I の「寄せの上限(bathtub)」では最小 0.767σ だった。
   - 今回の定理(閉じた形)で最小 **0.898σ**、積分の形のままなら最小 **0.909σ**。
   - 実際の最小は 0.946σ で、差は 4 % まで縮んだ。
   - 単一の線分では、定理の値と実際の値がほぼ一致した(σ = 10⁻³ で 0.9988 対 0.9991)。
3. **j = 1 の主張の範囲(一文):**
   **任意の状態について厳密に言えるのは線ごとの Cramér–Rao 不等式 Q(1)·J_ww ≥ (1 − λ_ρ)/(2(E_ρ[δ²] + σ²)) だけで、これが R の下限 1 − R ≥ Θ₁σ/(1 + Θ₁σ/2) − ε̃ − D(Θ₁ = 1 − σ²J_ww、σ → 0 で係数 1)に変わるのは、j = 1、つまりすべての y で σ²H_vv(y) = 1 となる状態——事前分布が W に平行な一本の直線の上に乗っている(幅ゼロの針を W 向きに置いた)状態——に限られる。**
   - 数値でも、W 向きの幅ゼロの針で Θ′ = 1 − σ²J_ww が成り立った(σ = 10⁻³、10⁻²、10⁻¹ で 10⁻¹³ 以内)。
   - 最良の単一ガウス(傾いた線分)は j = 1 − 6×10⁻⁸ で、この範囲のほぼ境目にいる。

話し言葉の絵:
- **「下限の鍵は、V 方向のピントが『どこに置かれているか』と『W 方向にどれだけ長く伸びているか』の掛け算(Θ′)である。」**
- **「一本の針ならピントは全長に均等に乗るので Θ′ = 1、余裕は σ。」**
- **「扇はピントを要(山頂)に少し寄せるので、Θ′ が 0.91 まで下がる。」**
- **「でも、ピントをどこまで寄せられるかを、窓の性質(H ≤ I/σ²)だけからは押さえきれない。そこが最後の一歩。」**

## 1. 状態ごとの定理と、その証明の流れ

### 記号(振り子、κ = 1)
- Y = X + σZ、p = p_Y、s = ∇log p、H = −∇²log p
- 事後平均 m(y) = y + σ²s(y)、事後共分散 Cov(X|y) = σ²I − σ⁴H(Tweedie)
- V/W 成分を使う。δ = X_q − π
- g(y) = 1 − ā(y) = E[sin²(δ/2) | y] ∈ [0, 1]:その場所で足りない伸び
- w(y) = σ²(H_vv(y))₊:V 方向のピントの重み
- u(y) = √2 (m_q(y) − π):事後平均の山頂からの距離
- j = E[w]、J = E[H](フィッシャー情報)、R = f + D(D は事後 Stein 欠損)

### 証明の流れ(各段の条件と道具)
1. **恒等式(厳密、条件なし)。** 振り子では Sym E[Df | y] = ā(y)·diag(1, −1) である。三項分解の f と、J = E[H] から:
   J_tot(1 − f) = E[g H_vv] − E[g H_ww] + 2J_ww
2. **H_vv の正負への分解(条件なし)。** E[g H_vv] = E[g w]/σ² − N、ただし N = E[g (H_vv)₋]。
3. **sin の不等式(すべての実数 x で成立)。** sin²(x/2) ≥ x²/4 − x⁴/48。事後分布で平均をとり、E[δ²|y] = u²/2 + Var(X_q|y) を使うと:
   g ≥ u²/8 + Var(X_q|y)/4 − E[δ⁴|y]/48
4. **Cauchy–Schwarz(条件なし)。** Λ = −E[w u s_w] とおくと、E[w u²] ≥ Λ²/E[w s_w²]。
   - これが「重みつき Cramér–Rao」である。重み w = 1 なら、部分積分で Λ = E[∂_w u] ≈ 1 となり、通常の Cramér–Rao(W 方向)に戻る。
5. **Tweedie による上限(条件なし)。** Cov(X|y) ⪰ 0 から H ⪯ I/σ²。よって 0 ≤ w ≤ 1、そして J_vv ≤ E[(H_vv)₊] = j/σ²。
6. **まとめ。** Θ′ = (|Λ|/j)·√(J_ww/E[w s_w²])、y = σ²J_ww/j とおく。
   ε = (E[w(E[δ⁴|y]/48 − Var(X_q|y)/4)] + σ²N + σ²E[g H_ww])/j とすると:
   1 − f ≥ [Θ′²σ²/(8y) + 2y − ε]/(1 + y)
7. **y についての最小化(初等的)。** y ≤ Θ′σ/2 では相加相乗平均、それより大きい y では 2y/(1 + y) で押さえる:
   [Θ′²σ²/(8y) + 2y]/(1 + y) ≥ Θ′σ/(1 + Θ′σ/2)
8. **結論(状態ごとの定理)。** R = f + D より:
   **1 − R ≥ Θ′σ/(1 + Θ′σ/2) − ε̃ − D、 ε̃ = ε·j/(σ²J_tot)**

   (段階K での修正:段6 では分子の正の部分だけを J_tot ≤ j/σ² + J_ww で割り、ε の部分は J_tot で正確に割る。こうすると符号の条件なしに成り立つ。当初の文面 max(ε, 0) は、分子全体が正のときに限って正しい。全 290 状態で分子は正なので、数値はほぼ変わらない:最小 0.8978 → 0.8977。)

- 使った不等式は 3、4、5、7 の四つだけ。どれも「積分が有限」以外の条件はない。
- 段6 の手前の形(J_ww と E[w s_w²] をそのまま使う形)を「積分の形」LB2 と呼ぶ。こちらの方が少し強い。

### 数値での確認(全 290 状態)

- 段3 は、全状態の全格子点で成立(最小の余り −6×10⁻¹⁶)。

- 段5 は、丸め誤差(相対 3×10⁻¹⁶)の範囲で成立。

## 2. 一様な c が出なかった所(どこで詰まったか)

c を一様にするには、全状態で Θ′ ≥ Θ₀ > 0 と ε̃ + D ≤ ησ(η 小)を示せばよい。そのとき:
**1 − R ≥ (Θ₀/(1 + Θ₀σ/2) − η)σ**

W 方向の部分積分で、Θ′ を作る Λ は二つに分かれる:
**Λ/j = E[w ∂_w u]/j(形の項)+ E[u ∂_w w]/j(ピントの傾きの項)**

- **形の項**は ∂_w u = 1 − √2σ²(e_qᵀHW) から来る。全状態で 0.963 以上だった。
  - ただし H には下限がない(谷では H が負に大きくなりうる)ので、一般には押さえられない。
- **ピントの傾きの項**は、ピントの重み w が山頂から離れるにつれてどれだけ減るか、を表す。
  - 扇や混合では −0.2〜−0.3 になる(扇が R\* を超える仕組みそのもの)。
  - これを押さえるには、∂_w w = σ²∂_w H_vv、つまり log p_Y の三階微分(事後分布の三次キュムラント)を制御する必要がある。
  - **H ⪯ I/σ² は w ≤ 1 は与えるが、w の変化の速さは与えない。** 混合では三次キュムラントに一般的な上限がない。
  - 「w の W 方向のフィッシャー情報 ≤ 定数 × J_ww」のような不等式を足せば閉じる。しかし、線分が交わる配置では w が短い距離で変わりうるので、この形の不等式は一般には成り立たないと考えている。
- それでも Θ′ が 0.91 で踏みとどまるのは、ピントを寄せると E[w s_w²] も一緒に小さくなり、比 J_ww/E[w s_w²] が大きくなって、傾きの項を打ち消すからである。
  - この「打ち消し」を不等式として取り出すことが、最後の一歩になる。
- ε̃ と D:σ ≤ 10⁻² の状態で、D/σ ≤ 0.0022。
  - ε/σ は、遠くに広い山を持つ状態(j ≈ 0.1)で最大 1.14 になる。そういう状態は Θ′ も大きいので、定理の値は 0.898 以上を保つ。
  - ただし一様な上限は示していない。

## 論文に書ける形(凍結用の文案)
- **定理(状態ごと):** 振り子のどの状態についても、1 − R ≥ Θ′σ/(1 + Θ′σ/2) − ε̃ − D が成り立つ。Θ′、ε、D はいずれも状態から計算できる量。
- **系(条件つき一様下限):** ある状態の集まりで Θ′ ≥ Θ₀ かつ ε̃ + D ≤ ησ ならば、1 − R ≥ (Θ₀/(1 + Θ₀σ/2) − η)σ。
- **観測:** 調べた 268 状態(σ ≤ 10⁻²)で、Θ′ ≥ 0.9125、状態ごとの下限 ≥ 0.898σ、実際の 1 − R ≥ 0.946σ。
- **未解決:** Θ′ の一様な下限。障害は「ピントの傾きの項」(log p_Y の三階微分)を、H ⪯ I/σ² だけでは押さえられないこと。
