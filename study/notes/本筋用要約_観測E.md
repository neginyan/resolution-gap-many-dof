## 0. 「8回中1回だけ 22/23」について

**最も考えられる原因:** 各段階の検査には「要約ファイルが元データから**完全に一致して**再現される」という項目がありました。この検査は、要約スクリプトを走らせ直して**保存ファイルを上書き**していました。

- 計算機や BLAS が違うと、浮動小数点の最後の桁がずれることがあります。
- その場合、**初回だけ**「完全一致」が崩れて FAIL します。同時にファイルが上書きされるので、2回目以降は PASS になります。
- これは「1回だけ落ちて再現しない」という症状とちょうど合います。ただし、こちらでは同じ失敗を再現できていないので、断定はできません。

**直したこと(全段階の検査に適用)**
1. 再現性の検査は、相対誤差 10⁻⁹ 以内で比べる方式に変えました。保存ファイルは**一切書き換えません**(実行後に元に戻します)。
   - 最後の桁を 10⁻¹⁵ だけずらしたファイルで試し、PASS になり、ファイルが変わらないことも検査に入れました。
2. **FAIL のときは、検査名を最後に一覧で表示**します。
3. 数値の許容誤差がある検査は、**許容誤差の何 % を使ったかを表示**し、10 % を超えるものを最後に一覧にします。
4. 段階Aの「fast_eval と一致」の検査を、絶対誤差 10⁻¹² から相対誤差 10⁻¹⁰ に改めました。

**監査の結果:**
- 許容誤差の 10 % を超える検査は二つだけで、どちらも 18 % でした。どちらも有限差分を使う近似の検査で、入力が固定なので結果は毎回同じになります。
- 今回の新しい検査を作る途中で、許容誤差 10⁻¹² がきつすぎる検査を一つ見つけ、10⁻¹⁰ に直しました。実際の誤差は 4.5×10⁻¹² で、上の名前表示の仕組みで見つかりました。

## 1. 中距離(0.1〜0.3)で、割合(超過分/距離)そのものを最大化する局所探索(図 stageE_local)

**出発点**
- A:割合 0.830 の状態
- B:R = 0.946 の状態

それぞれ歩幅 3 種類 × (成分数そのまま/一つ割って +1)の 12 本で探索し、良かった 3 本を 800 歩延長しました。

**分かったこと**
- **割合は 0.830 → 0.925(250 歩)→ 0.9515(延長後)まで上がった。** そのとき **R = 0.9854**(これまでの最大)。
  - 状態:K = 3、σ = 0.0054、谷間 0.062、P_v 0.0083、P_w 0.0063。
  - 細かい格子で計算し直しても、差は 5×10⁻¹⁵ でした。
- **上昇は鈍っているが、止まってはいない。** 延長の最後の 100 歩での伸びは +0.0002 / +0.0013 / +0.0010。最も良い鎖は飽和に近い形です。
- **A から出た鎖は、すべて距離 0.300(帯の上端)に張り付いた**(15 本中 9 本が 0.29 超)。距離 0.3 という枠そのものが効いており、枠を広げればさらに上がる可能性があります。
- B から出た鎖は 0.515 → 最大 0.885。成分を一つ割った鎖(K = 4)は最大 0.942 で、割らない鎖を超えませんでした。

**割合を決めている三つの量(厳密な関係)**

> 割合 = [ρ · CV · Ω · (1 − λ_ρ) + D] / 距離

- **ρ:** 局所の引き伸ばし ā と「ピントの超過」の相関
- **CV:** 山頂までの距離の分布 u = 1 − ā の変動係数(裾の重さ)
- **Ω:** ピントのずれの二乗平均

**最良の状態の内訳**
- 法則項は λ_ρ とほぼ同じで、差は 0.0049。つまり、ピントは平均としてはほぼ完全に引き伸ばし方向を向いている。
- ρ = 0.724、CV = 1.127、Ω = 1.184 で、**ρ·CV·Ω = 0.967**。
- 割合 ≈ 0.967 × 0.295 / 0.300 = 0.951。
- 話し言葉の絵:**「山頂までの距離のばらつき」×「ピントのずれ」×「その二つの揃い具合」が 1 に近づくと、余裕を使い切る方向に寄る。** 今のところ、この積は 0.967 で止まっています。

## 3. 上限の足場

**(a) |共分散項| ≤ √Var(ā) × (ピントのずれ)**
- ご提案の形(ピントのずれを一次の平均 E‖H−F‖/tr F で測る)は、**113 状態で破れた**(最大 2.12 倍)。
- Cauchy–Schwarz の形(ずれを二乗平均 Ω で測る)は、**全状態で成り立った**(最大 0.99998)。厳密な不等式です。

**(b) √Var(ā) ≤ C × 距離**
- u = 1 − ā(山頂までの距離の分布)を使うと、**ちょうど √Var(ā) = CV(u) × (1 − λ_ρ)** が成り立つ。1 − λ_ρ ≤ 距離 なので、**C = CV(u)** でよい。
- CV(u) は 0.004〜2.37(中央値 0.41)。ā の尖度とは別の量だった(順位相関 −0.43)。
- 合わせると、厳密に **R ≤ 法則項 + CV·Ω·(1 − λ_ρ) + D**。
  - 保存済みの 1536 状態では、この右辺が**すべて 1 未満**(最大 0.9945)。
  - CV·Ω < 1 は 1524 状態。残り 12 状態は、法則項と λ_ρ の差が補っていました。
- **ただし、探索で見つけた 100 状態では、14 状態で右辺が 1 を超えた**(最大 1.228。最良の状態では 1.094)。
  - 足場が負けるのは相関 ρ を 1 と置いているためで、実際は ρ = 0.72 程度です。
  - **CV·Ω < 1 は予想1に十分な条件だが、必要ではない。**

## 4. P_v ≥ 0、P_w ≥ 0 は谷間に対してどこまで保たれるか(図 stageE_valley)

- **P_v と P_w を直接小さくする敵対的探索(16 本)でも、負にはならなかった。** 最小は P_v = 0.00062、P_w = 0.0176。
- **最小にした状態は、谷間をほとんど使っていなかった。** (推測:P_v を小さくするには、谷間よりも「ā ≈ 1 の場所にピントを置く」方が効くように見える。地図ではまだ確かめていない。)
- 谷間の質量が 0.1 を超える状態でも、最小は P_v 0.011、P_w 0.0079。
- 観測した谷間は、質量で最大 0.34、平均の深さ 0.36 まで。その範囲では、どちらも正のままでした。
