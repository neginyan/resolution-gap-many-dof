(厳密計算のみ。全数値はコードで確認済み:verification/run_all_G.py 27/27 PASS。以前の段階も再実行:A 29/29・B 34/34・C 25/25・C+ 20/20・D 23/23・E 23/23・F 19/19 PASS)

## 結論(先に)
1. **山頂付近の二本の針について。**
   - **同じ形の針を混ぜると、R は必ず下がった。** 下がる量は (山頂からのずれ)² に比例し、同じく ā の差 Δā にも比例した。平らな山頂では、ずれは二乗でしか効かないからである。
   - **形の違う針を山頂で重ねると、R は少しだけ上がった。** ただし上がり分は、最も鋭い針の余裕 1 − max R_k の **2.7 % まで**だった。上がり分・余裕・Δā は三つとも窓 σ の **1 次**で消え、比 g は σ によらず一定(0.0269)だった。
   - 二本目の針を山頂からずらすと、上がり分は **ずれ² で減り**、すぐにマイナスに転じた。
2. **より強い傾向が見つかった:どの状態も「同じ窓で最良の単一ガウス」を超えない。** R ≤ R\*(σ) が 1591 状態すべてで成り立った。
   - R\*(σ) は、山頂に置いた細長い一本の針の値で、1 − R\* = σ(1 + O(σ)) である。
   - 予想1(R ≤ κ = 1)より一段強い形の予想になる。
3. **入れ子の格子で全状態を点検し直した。** 一様格子の上限に当たっていた 49 状態でも、結論はどれも変わらなかった。最大の差は 1.9×10⁻⁷ で、入れ子の格子の方がわずかに低かった。
4. **係数 c を式1から導いた。** c = 0.011832 に対して、測定は 0.011830(差 0.016 %)。
   - 針の極限では、ρ·CV·Ω < 1 は式1(単一ガウスで R < 1)から直接従う。

話し言葉の絵:**「同じ形の針を二本並べると、ピントが二か所に割れてぼやけるので、R は下がる。形の違う針を重ねると、ピントの縦横比が少しだけ良くなる。でもその得は窓の幅と同じだけ小さく、何を混ぜても『同じ窓でいちばん上手に作った一本の針』には届かない。」**

## 1. 山頂付近の二本の針(図 stageG_twoneedles)

### (a) 同じ形の針(山頂は q = π、a(q) = 1 − (q − π)²/4 + …)
三つの並べ方を、σ = 10⁻³ と 10⁻² で調べた(合計 176 状態)。
- 山頂を挟んで対称:π ± δ
- 一本は山頂、もう一本を V 方向にずらす
- 一本は山頂、もう一本を W 方向(針の長手方向)にずらす

| 量 | 結果 |
|---|---|
| はみ出し分 R − max_k R_k | **すべて ≤ 0**(最大 +9×10⁻¹³ は数値誤差) |
| ずれ² に対する次数(小さいずれ) | **1 次**(両対数の傾き 1.000〜1.001) |
| Δā に対する次数 | **1 次**(傾き 1.000〜1.001) |
| 係数(V 方向):下がる量 ≈ 0.9 × ずれ²/σ | σ = 10⁻³ で 893、10⁻² で 88 |
| 係数(W 方向) | 0.06(ほぼ下がらない) |

- 平らな山頂では ā ≈ 1 − (ずれ)²/4 なので、**Δā とずれ² は同じ次数**になる。だから「どちらで効くか」は区別できず、両方とも 1 次で効く。
- 下がる量 ∝ ずれ²/σ。余裕も ∝ σ なので、「余裕に対する割合」は (ずれ/針の幅)² で決まる。
- W 方向にずらしてもほとんど下がらないのは、針の長手方向に沿って動くだけで、ピントの形が変わらないから。

### (b) 形の違う針を山頂で重ねる
二本目の針の幅を r_v 倍、長さを r_w 倍にした。
- 209 点の地図のうち、**30 点で上がった(g > 0)**。最大は **g = 0.0269**(r_v = 0.50、r_w = 0.77)。
- σ を 10⁻² から 10⁻⁵ まで縮めると、**はみ出し分・余裕・Δā は三つとも σ の 1 次**で縮んだ(傾き 0.999)。
  - g は 0.02685〜0.02692 でほぼ一定。
  - はみ出し分/Δā = 0.134 で一定。
  - 山頂からのずれ² は 0(同心だから)。
- **ここでの答え:同心の形違いでは、はみ出し分は Δā の 1 次(= σ の 1 次)で消え、余裕と同じ速さで消える。** 余裕より速くは消えない。でも余裕の 2.7 % を超えることはなかった。

### (c) 二本目をずらす
- g の減り方は **ずれ δ の 2 乗**(傾き 2.000、W 方向 2.001)。言い換えると、山頂からのずれ² の 1 次。
- g がマイナスに転じる位置:
  - V 方向:針の幅の約 0.56 倍
  - W 方向:針の長さの約 1 倍

### (d) 2〜3 本の針の敵対探索(段階F 提案1)
| K | σ | g | R |
|---|---|---|---|
| 2 | 10⁻³ | 0.390 | 0.998456 |
| 2 | 10⁻⁴ | 0.208 | 0.999819 |
| 3 | 10⁻³ | **0.530** | 0.998477 |
| 3 | 10⁻⁴ | 0.474 | 0.999849 |

- g は (b) より大きくなった。しかしこれは、各成分の R_k が単独の最良より低いので、分母の「余裕」が大きいせいである。
- **R そのものは、同じ σ の最良の単一ガウス R\*(10⁻³) = 0.999001 より低かった。** これが 2 の発見につながった。

## 2. 最良の単一ガウスとの比較(図 stageG_bestsingle)
- **R\*(σ)** は、式1を中心・二つの幅・傾きについて最大化した値である(4 変数、5 つの初期値)。独立に、乱択 20000 点の探索で超えられないことも確かめた。
  - 山頂で、V/W 軸にそろえ、幅 s_v → 0 とした閉じた形:R = (1 + e^{−s_w²/4})/2 · s_w²/(s_w² + 2σ²)
  - これを s_w² ≈ 4σ で最大化すると、**1 − R\* = σ(1 + O(σ))**(σ ≤ 10⁻³ で相対誤差 < 7.5×10⁻⁴)。
  - 話し言葉では:「針を長くすると縦横比は良くなるが、長い分だけ山頂から外にはみ出す。その釣り合いで余裕 σ が残る」。
  - σ = 1 では R\* は 1/2 に下から近づく(無限に長い針の極限)。
- **全 1591 状態(段階A〜G のすべて)で R ≤ R\*(σ) だった。**
  - 余白の最小は 8.8×10⁻⁷(σ = 10⁻⁵ の同心二針)。
  - **g\* = (R − R\*)/(1 − R\*) の最大は −0.057**。どの状態も、最良の単一ガウスの余裕の 5.7 % 以上手前にいる。
  - 系列別の g\* の最大:同心の地図 −0.057、二針の族 −0.118、山頂近傍 −0.097、敵対探索 −0.51、段階F の針の列 −1.25。

## 4. 係数 c の導出(図 stageG_coefficient)
振り子では、どの状態でも Sym E[Df] = λ·diag(1, −1)(V/W 座標)となる。これと式1を合わせると、針の極限(ピントを針が独占し、D → 0)で次が成り立つ。

  **1 − ρ·CV·Ω ≈ (1 − φ_n) + φ_n (1 − λ_n)/(1 − λ_ρ)**

ここで:
- φ_n = (T_ww − T_vv)/(T_ww + T_vv) は針のピントの縦横比(T = S + σ²I)
- λ_n は針自身の引き伸ばし
- λ_ρ は重さの平均の引き伸ばし

段階F の縮め方(σ → tσ₀、幅 → t、長さ → √t)では、
- **c = 2(S_vv + σ₀²)/S_ww + (−cos q_k) S_ww / (8(1 − λ_ρ₀))** = 0.002513(ピントの項)+ 0.009318(引き伸ばしの項)= **0.011832**
- 定数項 c₀ = (1 + cos q_k)/(2(1 − λ_ρ₀)) = 2.4×10⁻⁶。針が山頂から 0.0021 ずれているための床。

| t | 1 − ρCVΩ(測定) | 式1による予測 | c₀ + c t |
|---|---|---|---|
| 1 | 1.197×10⁻² | 1.172×10⁻² | 1.183×10⁻² |
| 0.1 | 1.185×10⁻³ | 1.184×10⁻³ | 1.186×10⁻³ |
| 0.01 | 1.2070×10⁻⁴ | 1.2068×10⁻⁴ | 1.2072×10⁻⁴ |

- 測定の傾き 0.011830 に対して予測は 0.011832(差 0.016 %)。予測の相対誤差は t に比例して縮む(2×10⁻² → 2×10⁻⁴)。
- 同じ絵で「物差し効果」も式になる:1 − 割合 ≈ (1 − R_針)/(1 − 法則項)。誤差は t = 0.01 で 9×10⁻⁴。
- **針の極限での ρ·CV·Ω < 1 は、φ_n < 1 と λ_n < 1(式1、単一ガウス)から直接出る。** 話し言葉では:「1 − ρCVΩ は、針のピントの縦横比の残りと、針の長さが山頂からはみ出す分(を遠い山の余裕で割ったもの)の和。どちらも 0 にはならない」。
- ただしこれは針の極限での導出で、一般の状態での証明ではない。

## 分かったこと/まだ分からないこと
**分かったこと(観測)**
- 同じ形の二針は、R を必ず下げる。下げ幅は ずれ² ∝ Δā の 1 次。
- 形の違う同心の二針は R をわずかに上げる。上げ幅は Δā ∝ σ の 1 次で、余裕の ≤ 2.7 %。
- 全状態で R ≤ R\*(σ) で、余白は余裕の 5.7 % 以上。
- 係数 c は式1で 0.016 % まで説明できる。

**まだ分からないこと**
1. **R ≤ R\*(σ) の証明。** 成り立てば R ≤ R\*(σ) < 1 = κ となり、予想1を含む。
2. R\*(σ) の厳密な形。閉じた形(V/W にそろえた針)は下界である。傾きを入れるとわずかに上がる(σ = 10⁻⁴ で 1×10⁻⁹、σ = 0.1 で 1×10⁻³)。
3. 窓 σ が状態によって「実効的に」違う場合(例えば遠い太い山)にも、比較の基準として R\*(σ) が正しいのか。今回は同じ σ で比べた。

## 推測(観測が支える範囲に限る)
- **予想1′:どの状態も、同じ窓の最良の単一ガウスを超えない(R ≤ R\*(σ))。** 根拠:1591 状態で余白 ≥ 5.7 %。最も迫ったのは「形の違う同心の針」だった。
- これが正しければ、「混合は得をしない」という形で予想1が言い直せる。証明の道筋としては、混合のピント(フィッシャー情報)を成分ごとに分け、各成分を式1で押さえる方向が自然に見える。

## 次に測るもの(提案)
1. **R ≤ R\*(σ) への敵対探索。** 目的関数を g\* にして、K = 2〜4、σ = 10⁻⁴〜0.3 で探索する。特に「形の違う同心の針」の周りを重点的に。
2. **R\*(σ) の 2 次の項。** 傾き込みの最適化を解析的に展開し、1 − R\* = σ − a σ² + … の a を求める。数値と照合する。
3. **二成分の同心ガウスについて、R ≤ R\* を式で示せるか。** 共分散項を Δā と縦横比の差で書き、その符号と大きさを調べる。
