   - ただし「面の割合で薄まるだけ」と考えた見積もり f × (1 自由度の得)は、それでも 1.4〜1.9 倍の過大評価になる。
     - 面の中の得そのものが、1 自由度より小さい。
3. **N2:P だけでは正の下限はない。W 方向の細かさ y/σ に上限をつけると、P はおよそ 0.85 で止まる。**
   - 反例:σ = 10⁻² で P を直接最小化した。すると P = 1.2×10⁻⁴ まで下がった。
     - そのときの値は y/σ ≈ 100、d ≈ 0.001、ギャップ ≈ 100σ。
     - つまり、ギャップは大きいまま、P だけが潰れる。
   - したがって「P ≥ P₀ > 0」という形の一様な不等式は成り立たない。この形の証明は**見込みが薄い**。
   - 一方、y/σ ≤ Y の制限のもとでの P の最小は次のとおりだった。
     - K = 8:0.861〜0.883
     - K = 16(反復が少ない):0.851〜0.856
   - その状態でも、ギャップ/√P は 0.994〜2.25 だった。√P とほぼ同じか、それ以上。
   - 制限つきの一様ギャップには**方針がある**(4 節):「W 方向に滑らかな状態では ρ ≤ ρ₀」を示せば足りる。
   - 閉じた形の P₀ は見つからなかった。K を増やすと最小値がまだ下がっている。
4. **N3:接線の束の「長さ 0.44√σ」の起源が、ほぼわかった。**
   - 片の長さ ℓ を固定してほかを最適化すると、ギャップの曲線は ℓ ≈ 0.43√σ で最小になる。
     - 曲線はよく合う:0.4931 + 0.00285/ℓ + 0.0179ℓ²(ℓ は √σ 単位、rms 2.5×10⁻⁴)。
     - 短い片は「ぼけ」で損をする(1/ℓ の項)。長い片は「回転からのずれ」で損をする(ℓ² の項)。その釣り合いで長さが決まる。
   - 動径の形を変えた族 f = (p, −q)/(1 + r^{2m})(κ = m/4、回転の速さは 1/√2 のまま)で調べた。
     - 最適値は m²/2 + 0.003 で、+0.003 は m によらない(m = 0.7, 1, 1.4)。
     - 最適な長さは m によらない(0.431〜0.439)。
   - ⇒ 長さを決めるのは回転の速さで、伸びの大きさではない。
     - スケールの議論(厳密)から、ℓ_opt = c √(σ / 曲率)、c ≈ 0.36 になる。
     - 弧から片がはみ出す高さ(サジッタ)にすると、約 0.065σ。

話し言葉の絵:

- **N1**:1 自由度では、ピントを「何枚かの像に分けて重ねる」と得をする。多自由度では、その工夫が効くのは V⁺–W⁺ の面の中だけになる。
  - 面の外(q⁻ の方向)は一枚のガウスのままでよい。
  - しかも面の中で像を分けると、面の外との「ねじれ」の割に合わなくなって、q⁻ の側が少し損をする。
  - だから得は、面の割合 f で薄まるより速く(f^2.6 ぐらい)小さくなる。
- **N2**:「ピントの広がり × W 方向の細かさ」は、両方をいっぺんに小さくはできない、という不確定性の絵だった。
  - ところが W 方向をうんと細かくすると、ピントの広がりのほうを 0 に近づけられてしまう。
  - そうすると、ギャップは別の理由(y が大きいことそのもの)で大きくなる。
  - だから正しい形は「P が小さいか、y が大きいか、どちらかでギャップが出る」の二股になる。
- **N3**:曲がった道に、まっすぐな定規を並べて沿わせる絵。
  - 定規が短すぎると、目のぼけ(σ)で定規の向きがはっきりしない。
  - 長すぎると、道の曲がりからはみ出す。
  - ちょうど「はみ出しが σ の 6〜7%」になる長さが最適で、それは回転の速さだけで決まる。

## 1. N1:多自由度での混合の得(論文 C §VI)

### 1.1 方法

- **状態の族**:「積の状態」を使った。
  - (V⁺, W⁺) 面の中は、K 個のガウスの混合。
  - それに直交する q⁻ 方向は、共通の 1 本のガウス(幅 s_b)。
  - 二つを角 θ だけ回して組み合わせる。p⁻(運動量だけの方向)は無限に長くする(段階M で、コストゼロと確認済み)。
  - q⁻ 方向の積分は閉じた形で書ける(n_tools.py)。だから評価は 2 次元格子で済み、速い。
- **評価器の確認**:
  - 3 次元評価器(段階M の m3_mix.R3)とは、ランダムな積の混合で gap/σ が 2×10⁻⁶ 以内で一致した。
  - 1 本のガウスでは、4 次元の法則 1 とも 10⁻⁶ 以内で一致した。
- **最良ガウスは、この族の中にある**。
  - 族の中での最良ガウスは、本当の最良より相対 1.2×10⁻⁴ だけ上だった(格子の分)。
  - 比は、本当の最良(M1 の値)を分母にして計算した。
- **探索**:二つの系で手順と手間をそろえた。
  - 段階H の K = 8 の最良状態の重い成分、または段階L の K = 16 の磨いた状態から始める。
  - 山登り 1500 歩、次に L-BFGS-B(K ≤ 8 は 300〜1000 反復、K = 16 は 100 反復)。
  - 連成系には、二つ目の出発点を加えた。1 自由度の最適を面に埋め込み、q⁻ はガウスの法則にする("from1d")。
  - 二つの出発点の結果は、K = 8 で 6 桁一致した。
  - K = 4 では、一つ目の出発点の結果は悪い局所解だった(後述)。

### 1.3 得の内訳(N1(b)、混成分解、K = 8)

分解のやり方:

- G は最良ガウス、M は最良の混合。
- H は「M の面の混合 + G の q⁻ の法則」を組み合わせた状態。
- 次のように分ける。
  - 得 = (G → H:面の混合だけ) + (H → M:q⁻ の法則の手直し)
  - さらに、面の混合だけの部分 = d_plane(面の項だけの変化) + d_cross(q⁻ との交差項の変化)
- この分解は恒等式で、検証では 10⁻¹² で合う。

読み取れること:

- **仮説 (2)「面の混合が q⁻ のコストを上げる」は確認された**。d_cross < 0 が全 K で成り立ち、ε と K が大きいほど強い。
- 混合は、q⁻ の幅を広げ、回転 θ を戻す方向に q⁻ の法則を動かす。それで交差項の損を一部取り返している。
- 交差項の損を除いた d_plane でも、f × (1 自由度の得)の 0.6〜0.7 倍しかない。
  - つまり、得が小さくなる理由は二つある。
    1. 面の中での得そのものが小さい。
    2. 交差項の損がある。
- 理由 1 については、仕組みの推定がある。
  - 回転 θ があると、面の中の「W 方向」が q⁻ と混ざる。
  - そのため、1 自由度の山頂の形(sech² の扇)を、そのまま写せない。
  - これは推定で、確かめていない。

## 2. N2:P の直接最小化(振り子、σ = 10⁻³, 10⁻²)

  - 状態は自由な混合(段階H の形)。

**(a) 下限について**

- **制限なしの P は、正の下限を持たない(数値の反例)。**
  - σ = 10⁻² で、y/σ ≈ 100 の状態を見つけた。そこではピントの重みがほぼ山頂の一点に集まり(d ≈ 0.001)、P = 1.2×10⁻⁴ まで下がる。
  - この状態のギャップは約 100σ で、大きい。y が大きいこと自体が、ギャップを作っている(段階M の二変数の式 (d²/8 + κ₂y/σ)/(1+y) の第 2 項)。
  - だから「gap ≳ √P」は崩れない。崩れるのは「P ≥ P₀」のほうだけ。
- **制限つき(y/σ ≤ Y)では、P の最小は 0.85〜0.88 で止まった。**
  - ただし K = 16(25〜50 反復)で、段階M の下限 0.858 を下回った(0.851)。
  - K を増やすと、まだ少し下がる。下限の値は決まっていない。
- **ギャップ ≈ √P は、P を最小化した状態でもほぼ成り立った。**
  - ギャップ/√P = 0.994〜1.01(y/σ が小さいとき)。
  - ただし、これまでに保存した状態の中には 0.878 まで下がるものがある。
  - だから「gap ≥ c√P」の c は 1 ではなく、0.88 程度と見るのが正直なところ。

**(b) 証明の道筋の判定**

- 「P ≥ P₀ を一様に示す」:**見込みが薄い**(上の反例で偽だから)。
- 「二股の形で一様ギャップを示す」:**方針がある**。
  - y/σ が大きいとき:二変数の式の第 2 項から、ギャップ ≳ κ₂·y/(σ(1+y)) が出る。
  - y/σ ≤ Y₀ のとき:Θ′ ≥ geo·(1 − ρ) を使う。だから「W 方向に滑らかな状態では ρ ≤ ρ₀ < 1」を示せば足りる。
  - データ:保存した状態のうち y/σ ≤ 0.5 では ρ ≤ 0.274、y/σ ≤ 5 では ρ ≤ 0.310 だった。P を最小化した状態でも、ρ = 0.24〜0.27 だった。
  - ρ が大きい状態(ρ = 90)は、y/σ = 1242 のものだけだった。つまり二股の反対側にいる。
  - ρ ≤ ρ₀ を、ガウス平滑化の性質(W 方向の平滑化が Hessian を抑える)から示すのが、次の一歩になる。
  - 証明はまだない。
- **P₀ の閉じた値は見つからなかった。**
  - 連続な扇(sech² の形)では 0.905、自由な混合では 0.851 まで下がる。
  - 閉じた値の候補は、出せる段階にない(推定もしない)。

## 3. N3:接線の束の長さの起源(ねじれ流れ、σ = 10⁻³)

**(a) ギャップを片の長さの関数として見る**

- 片の長さ ℓ を固定し、残りの 5 つのパラメータを最適化した(片の数 n ≥ 64)。

  | ℓ/√σ | 0.1 | 0.2 | 0.3 | 0.44 | 0.6 | 0.8 | 1.0 | 1.4 |
  |---|---|---|---|---|---|---|---|---|
  | (κ−R)/σ | 0.5204 | 0.5080 | 0.5043 | 0.5031 | 0.5043 | 0.5076 | 0.5140 | 0.5453 |
  | 最適な曲率の大きさ | 0.7071 | 0.7073 | 0.7083 | 0.7123 | 0.7255 | 0.761 | 0.814 | 0.926 |

- フィットは 0.4931 + 0.00285/ℓ + 0.0179ℓ²(0.2 ≤ ℓ ≤ 1、rms 2.5×10⁻⁴)で、最小は ℓ_opt = 0.431√σ。
  - 0.3〜0.6 の範囲の放物線で見ると、頂点は 0.450。
- ℓ ≤ 0.44 では、片を並べる曲線の曲率は、回転の速さ 1/√2 に 0.7% 以内で一致した。
  - 長い片ほど、曲率は大きくなる。片の両端のはみ出しを打ち消すため、と考えられる。

**(b) 「回転のぼけ」の式(推定)**

- 1/ℓ の項はピントのぼけ、ℓ² の項は回転からのずれ、と読める。
- 二つの係数の比から、ℓ_opt = (a/2b)^{1/3}。
- 単純な見積もり「ずれの損の係数 b = 2κk²」(k は道の曲率)では、ℓ² という形は合う。しかし係数は 0.25 と出て、フィット値 0.018 と一桁以上違う。
  - 係数の導出は、まだできていない。

**(c) 動径の形への依存**

- f = (p, −q)/(1 + r^{2m}) で調べた。r = 1 で κ = m/4、回転の速さは 1/√2 のまま。

  | m | κ | 最適 (κ−R)/σ | 推定 m²/2 | まっすぐなガウス √(m⁴/4 + m²/2) | ℓ/√σ | 曲率 |
  |---|---|---|---|---|---|---|
  | 0.7 | 0.175 | 0.24760 | 0.2450 | 0.552 | 0.433 | 0.710 |
  | 1 | 0.25 | 0.50314 | 0.5000 | 0.866 | 0.431 | 0.712 |
  | 1.4 | 0.35 | 0.98302 | 0.9800 | 1.393 | 0.439 | 0.717 |

- 束の最適は、ほぼ「m²/2 + 0.003」になった。
