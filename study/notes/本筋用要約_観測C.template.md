## 提案1:谷間を狙った敵対的探索 — 見つかった最大の R/κ

設定:振り子(κ = 1)、成分数 K = 2, 3、σ = 0.03, 0.1, 0.3, 1。目的関数は3種類、合計 24 の探索。
- R そのもの
- 超過分(= 共分散項 + D)
- 余裕比(= 超過分 / (κ − 法則項))。予想1 ⟺ 余裕比 ≤ 1。

各探索の最良状態は、全解像度で再計算し、さらに 1.5 倍の格子で確かめた(差 < 10⁻⁸)。

**分かったこと**
1. **見つかった最大の R/κ は 0.9462**(K = 3、σ = 0.03)。κ = 1 には届かなかった。
   - 内訳:法則項 0.889 + 共分散項 0.057 + D 0.0000。谷間の質量 0.150、重なり 0.65。
   - この値は、段階Aの単一ガウス(鋭い山を π に置いたもの)の 0.9495 より小さい。単一ガウスは山を細くすれば R → 1 に近づけられる。したがって「R/κ が 1 に近い」こと自体は危険の印ではない。注目すべきは超過分の方である。
2. **超過分が大きくなるのは、法則項が小さいときだけだった**(図 stageC_adversarial 左)。
   - 超過分の最大は 0.603 で、そのとき法則項は −0.681。
   - 法則項 + 超過分(= R)は、全状態で 0.946 を超えなかった。
3. **余裕比の最大は 0.714。** ただしこれは、重なり 0・谷間 0 の状態(離れた二つの山)だった。重ならなければ R = R_sep ≤ λ_comp ≤ κ が成り立つので、危険な状態ではない。
4. **「谷間が危ない」という見込みは、小さい σ では支持されなかった。** 谷間の中から来る共分散項の範囲は次のとおり。
   - σ = 0.03:−0.137〜+0.017
   - σ = 0.1:−0.037〜0
   - σ = 0.3:−0.003〜+0.071
   - σ = 1:+0.047〜+0.110
   - つまり σ が小さいと谷間はむしろ R を下げる側に働き、σ が大きい(0.3〜1)と上げる側に回る。

## 提案3:ピントと引き伸ばしの地図(図 stageC_spatial)

段階Bの基本形 A、段階Aの反例 B、上の最大状態 C について、四つを描いた。
- 局所の引き伸ばし E[a|y]
- 局所のピントの異方性
- 谷間
- 共分散項の密度。W 方向に沿った断面も付けた。

**分かったこと**
- **A と B では、段階Bの解釈「ピントの鋭い場所が、引き伸ばしの強い場所に偏る」が地図で確かめられた。**
  - 細く長い山は、中心(安定点、引き伸ばしほぼ 0)から両端の双曲点付近(引き伸ばし ≈ 1)まで届いている。
  - ピントの超過(H − F の異方性)は両端で大きく、中心で負。
  - 共分散項は、外側半分から +0.099、内側半分から −0.005 だった(A)。B は外側 +0.086、内側 +0.014。
- **谷間は、細い芯と太い裾のつなぎ目に沿って、細い帯として現れる。** そこでの共分散項の密度は負だった(A:−0.069、B:−0.056、C:−0.137)。
- **C では、共分散項は π にある細い成分の上(内側)から来ていた。** 引き伸ばしとピント超過の、p_Y で重みづけた相関は A 0.33、B 0.36、C 0.54。

## 提案2:D の大きさを決める量(図 stageC_D)

**厳密な分解**:D = D_within + D_between(誤差 2×10⁻¹¹)。事後分布は「いくつかの推測(成分)の混合」なので、次の二つに分かれる。
- **D_within**:推測ごとの幅が違う分
- **D_between**:推測と推測の間で流れが曲がる分

1152 状態(|D| > 10⁻⁸ は 867)で測った。
- **主役は D_between。** D_within の占める割合の中央値は 0.32。D の符号は D_between の符号と 74% で一致した。
- **候補 S_D(推測の散らばり × 曲がり / (σ⁴ tr F))は順位相関 0.90 で強く連動した。**
  - σ ≤ 0.3 では、|D| ≤ 0.72·S_D がすべての状態で成り立った。
  - σ = 1 では、比が最大 2.20 まで超えた(6 ケース)。超えたケースはすべて D_between が主だった。
- **ご提案の「責任度の分散 × 成分間の引き伸ばしの差」は、順位相関 0.65 にとどまった。** 比は最大 938 まで振れるので、上限には使えない。

## 提案4:他の流れ(四次の振動子 g = −q³、二重井戸 g = q − q³)(図 stageC_otherflows)

**分かったこと**
- **式1と三項分解は、どちらの流れでもそのまま成り立った。**
  - 単一ガウス 300 ケースで、式1との差は < 10⁻¹⁰。
  - 四次の振動子は、元のリポジトリの fast_eval.py と一致した。
  - 二重井戸は、総当たり計算で R・(f)・D(= +0.041)を 4×10⁻⁶ 以内で再現した。
- **段階Bの余りの式が一般化された:R − e = −E_ρ[g‴(q)]·K_qq·K_qp / tr F。**
  - 振り子は g‴ = cos q の特別な場合。四次・二重井戸では g‴ = −6。
  - したがって、どの流れでも |R − e| ≤ σ²·|E_ρ[a″]| が成り立つ(a = (1 + g′)/2 は引き伸ばし)。
- **共分散項の符号は、引き伸ばしの曲がり a″ の符号に従った**(中心を重ねた家族)。
  - 振り子・中心 q = 0(a″ > 0。外へ行くほど引き伸ばしが強い):共分散項は正。幅の比 1/2/4.4/8 で +0.001/+0.036/+0.095/+0.099。
  - 四次・二重井戸(a″ = −3 < 0。外へ行くほど引き伸ばしが弱い):l₁ = 1 では −0.005/−0.115/−0.265/−0.188 と負になった。
  - 例外は、幅の比 8・l₁ = 0.5 の +0.085 の一つ。このとき山2は、引き伸ばし方向の幅(0.72)が縮み方向の長さ(0.315)より大きく、細長い向きが入れ替わっている(推測:向きが入れ替わったことで符号も反転した)。
  - 「ピントが鋭い場所が、引き伸ばしの強い所にあるか弱い所にあるか」で符号が決まる、という絵と合う。
- **四次と二重井戸では、共分散項も D も完全に一致した**(差 < 10⁻¹³)。中心を重ねた状態は点対称なので、引き伸ばしの一次の変化は効かず、二階 a″ だけが効く。a″ は二つの流れで同じなので、一致すると考えられる。
- **ランダムな混合 800 ケースでは、R > λ_comp は 0 件だった**(R/λ_comp の最大は四次 0.905、二重井戸 0.770)。R > λ_ρ は 32 件。(f) は (e) より R に近かった(中央値 0.0022 対 0.0086)。
- 注意:この二つの流れは、引き伸ばしに上限がない(κ = ∞)。予想1はここでは自明に成り立つので、確かめたのは「仕組みが同じか」だけである。

## まだ分からないこと
1. **予想1は開いたまま。** 法則項 + 超過分が κ を超える状態は見つかっていない(最大 0.946)。「超過分が大きいのは法則項が小さいときだけ」という釣り合いがなぜ起こるのかは、まだ式で説明できていない。
2. **谷間の寄与が、σ が小さいと負、大きいと正になる理由。**
3. **D の上限。** S_D は σ ≤ 0.3 ではよい目安だが、σ = 1 では D_between が S_D を超える。推測ごとの事後の幅の違い(e^{−v/2} の差)を取り込んだ尺度が要りそうだが、未確認。
4. 成分数 4 以上、高次元(例:結合した二つの振り子、4次元位相空間)では未確認。

## 推測(観測が支える範囲に限る)
- R を κ に近づけるのは、主に法則項(鋭い山を双曲点に置くこと)である。共分散項と D は、法則項の「余り」を埋めるほどには大きくならない。今回の 24 の敵対的状態と、振り子のその他約 1,500 状態(ランダム混合 1000、測定1の 512)では、例外はなかった。
- 共分散項は「ピントの鋭さ」と「引き伸ばし」の場所の一致で決まり、符号は a″ と山の向きで決まる。この絵は三つの流れで成り立った。

## 次に測るもの(提案)
1. **釣り合いの式を試す。** H を正の部分 H₊ と負の部分 H₋ に分け、(f) ≤ E[λmax(G)·tr H₊ − λmin(G)·tr H₋] / E[tr H] のような上限を数値で確かめる。谷間の寄与をこの形で抑えられるかを見る。
2. **D の改良尺度**(事後の幅の違いを入れたもの)を作り、σ = 1 での超過が消えるか確かめる。
3. **σ = 0.3〜1 で、谷間の正の寄与を最大化する敵対的探索。** 谷間が R を上げる側に回る領域を狙う。
