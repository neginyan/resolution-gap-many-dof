# 本筋用要約 — 観測研究 段階C+:釣り合いの上限と「曲がり」の絵

(厳密計算のみ。全数値はコードで確認済み:verification/run_all_C5.py 20/20 PASS。段階B 34/34・段階C 25/25 も再実行して PASS)

対象:段階B・Cで計算した全状態を、新しい量を加えて計算し直した。振り子 1536 状態(ランダム混合 1000、測定1 512、敵対的 24)と、四次・二重井戸 816 状態。

## 0. まず分かった、振り子に特有の厳密な関係
振り子では、引き伸ばし a(q) = (1 − cos q)/2 と、その曲がり a″(q) = cos q / 2 の和が、どこでも ½ になる:**a + a″ = ½**。

したがって、状態が感じる曲がり E_ρ[a″] = ½ − λ_ρ(誤差 6×10⁻¹⁷)。また、法則項 ≤ λ_ρ なので、

> 山頂からの距離 κ − 法則項 ≥ ½ + E_ρ[a″]

話し言葉にすると、「引き伸ばしの山頂の近くは、必ず下向きに曲がっている」。振り子では「山頂からの距離」と「曲がり」は独立な量ではなく、同じものの裏表になっている。

## 1. ご質問:超過分 ≤ (κ − 法則項) を、曲がりの符号で説明できるか(図 stageC5_curvature)

**結論:符号だけでは説明できなかった。ただし「山頂に近い状態ほど、余裕を使い切らない」という傾向は見えた(例はまだ少ない)。**

- **超過分 ≤ κ − 法則項(= R ≤ κ)は、1536 状態すべてで成り立った。** 余裕を使った割合の最大は 0.714。
- **共分散項の符号は、曲がりの符号とほとんど一致しなかった。**
  - 一致したのは 59%(1535 状態)で、偶然とあまり変わらない。
  - 曲がりが負なのに共分散項が正の状態が 254、曲がりが正なのに負の状態が 368 あった。
  - 共分散項の最大 0.603 は、曲がりが負の状態で出た。
  - 四次・二重井戸は、曲がりがどこでも −3(負)である。それでも、ランダム混合で共分散項が正 418、負 396 と半々だった。段階Cの「符号は曲がりに従う」は、中心を重ねた家族の中だけの話だった。
- **共分散項がどこから来るかは、はっきりしていた。** 共分散項が正の状態では、その全量(中央値 1.06 倍)が、局所の曲がりが負の場所、つまり引き伸ばしの山頂に近い場所から来ていた。曲がりが正の場所からは、少し負の寄与がある。
  - ただし振り子では、局所の曲がり < 0 は「その場所の引き伸ばし > ½」と同じことである。だからこれは「ピントの鋭さの超過が、引き伸ばしの強い場所に重なると R が上がる」という段階Bの絵の言い換えで、新しい情報は少ない。
- **山頂からの距離で区切った、超過分の最大(と、余裕を使った割合の最大)**

| 距離 κ − 法則項 | 状態数 | 超過分の最大 | 割合の最大 | 状態が感じる曲がりの範囲 |
|---|---|---|---|---|
| 0〜0.3 | 6 | 0.057 | 0.515 | −0.44〜−0.30 |
| 0.3〜0.6 | 24 | 0.320 | 0.714 | −0.44〜+0.09 |
| 0.6〜1.0 | 950 | 0.490 | 0.633 | −0.49〜+0.48 |
| 1.0〜2.0 | 556 | 0.603 | 0.359 | −0.49〜+0.49 |

- 山頂に一番近い組(距離 < 0.3)は、曲がりがすべて強く負で、超過分は 0.057 以下、余裕の半分ほどしか使っていない。「山頂付近は下向きに曲がっているので、超過分が育たない」という絵と合う。ただし 6 状態しかないので、まだ傾向としか言えない。
- 割合の最大 0.714 は、距離 0.37・曲がり −0.17 の状態で出た。これは重なりも谷間もない二つの離れた山で、R = R_sep ≤ λ_comp が成り立つので危険ではない。

## 2. 提案1の続き:釣り合いの上限 B(図 stageC5_balance)

局所の鋭さ H を正の部分と負の部分(谷間)に分けると、厳密な不等式が得られる。

> (f) ≤ B = E[|a|·tr|H|] / E[tr H]、 したがって R ≤ B + D

- **不等式は、全状態(三つの流れ、2352 状態)で成り立った。**
- **谷間がない状態では、B ≤ κ が成り立つ**(314 状態、B の最大 0.992)。これは式の上からも言える。
- **谷間があると、B は κ を超えうる。** B > 1 は 21 状態(すべて谷間の質量 ≥ 0.012)で、最大 1.121。
  - **R が最も κ に近い状態(0.946)も、この 21 状態に入っていた。** つまり B では、肝心の状態について予想1を保証できない。
- **B の緩さ(B − f、中央値 0.26)は、主に谷間から来ているわけではなかった**(谷間の質量との順位相関 −0.30)。
  - 谷間のない状態では、緩さは 2E[a·(wᵀHw)]/E[tr H](wᵀHw は縮み方向 W のピントの鋭さ)と書ける。B は「ピントがすべて引き伸ばし方向に揃っている」と仮定した上限なので、縮み方向にピントが合っている分だけ緩くなる。

## 推測(観測が支える範囲に限る)
- 振り子では a + a″ = ½ なので、「山頂に近い」と「下向きに曲がる」は同じことである。山頂付近で超過分が小さいことは、ここから来ているのかもしれない。6 状態の観測と合っているが、まだ例が少ない。
- 超過分が大きくなれるのは、山頂から遠い状態だけだった(超過分 > 0.4 はすべて距離 > 0.6)。

## 次に測るもの(提案)
1. **山頂の近く(距離 < 0.3)だけを狙った敵対的探索。** 目的関数は超過分 / 距離。例を 6 から数百に増やし、割合が 1 に近づけるかを見る。
2. **B から縮み方向のピントの分を差し引いた、締めた上限 B′ = E[|a|·(tr|H| − 2·(wᵀHw)₊)]/E[tr H] を試す。**
3. 四次・二重井戸の「曲がり負・共分散正」の混合を一つ取り、段階Cと同じ地図で仕組みを見る。
