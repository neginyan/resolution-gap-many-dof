## 結論(先に)
1. **段階J の段6 を修正した。**
   - 分子を「正の部分」と「ε の部分」に分ける。正の部分だけを J_tot ≤ j/σ² + J_ww で割り、ε の部分は J_tot で正確に割る。
   - これで符号の条件なしに成り立つ。ε の項は ε̃ = ε·j/(σ²J_tot) になり、max(ε, 0) は不要になった。
   - 係数 j/(σ²J_tot) は全状態で 0.938〜1.155、正の部分は ε j/σ² の 1.66 倍以上(ご指摘の値と一致)。
   - 数値はほぼ変わらない:最小 0.8978 → 0.8977。
2. **なめらかにした重み χ を使うと、「ピントの傾きの項」は消せた。代わりに、一様な c は三つの量の下限に帰着した。**
   - 三つの量とは、なめらかにしても残るピントの割合 α、形の項 G、山頂から遠い広い山の補正 ε₂ である。
   - これらがある状態の集まりで下限(と上限)を持てば、1 − R ≥ cσ が式で出る。
   - 保存済みの「山頂に集まった」236 状態に当てはめると、λ = 1 で **c ≈ 0.34**(各状態の下限そのものは ≥ 0.389σ)。
   - 最良の混合・扇では約 0.47〜0.50σ、単一の線分では 0.79σ。
3. **条件なしの一様な c は、今回も出なかった。**
   - 成分数 K の上限や成分の太さの下限を仮定しても、α・G・ε₂ の下限は証明できなかった(理由は 2 節)。
   - **条件なしで一様に言えるのは K = 1(単一ガウス)だけ**:1 − R ≥ 1 − R\*(σ) = σ − (7/8)σ² + …(段階H の厳密な式)。

話し言葉の絵:
- **「ピントの重みを、W 方向にゆっくりしか変われないように『ならす』。」**
- **「ならした分だけピントは目減りする(α)が、代わりに『ピントが山頂に急に寄る』効果を数えなくてよくなる。」**
- **「ならし方を強くすると目減りが増え、弱くすると傾きの代償 1/(1 + λ) が残る。その釣り合いで、扇でも余裕の半分(0.5σ)は保証できる。」**
- **「ただし『目減りが少ない』こと自体は、まだ観測でしか言えていない。」**

## 1. なめらかにした重み χ

### 作り方
- 速さ L > 0 に対して、χ を次の条件を満たす最大の関数とする:
  - 0 ≤ χ ≤ w(w = σ²(H_vv)₊)
  - √χ が W 方向に (L/2)-リプシッツ
- 式では √χ(v, w₀) = min over w′ (√w(v, w′) + (L/2)|w₀ − w′|)。格子上では、前向きと後ろ向きの二回の走査で求まる。
- 性質は二つ:
  - |∂_w χ| ≤ L√χ
  - g ≥ 0 なので E[g w] ≥ E[g χ]
- 最初は「log χ がリプシッツ」で試した。しかしこれだと、W 線上に w = 0 の点が一つでもあれば、その線全体で χ = 0 になる。混合で α が 0〜0.4 まで潰れたので、√χ 版に変えた。

### 段階J の鎖に入れる(各段は条件なし)
- (3′) Z := E[χu²] ≥ Λ_χ²/A_χ。ここで Λ_χ = −E[χ u s_w] = E[χ ∂_w u] + E[u ∂_w χ]、A_χ = E[χ s_w²] ≤ J_ww。
- (4′) |E[u ∂_w χ]| ≤ L·E[|u|√χ] ≤ L√(Z·P_χ)。P_χ は χ > 0 となる確率(≤ 1)。
- 二つを合わせると √Z ≥ (j_χ G_χ)₊/(√A_χ + L√P_χ)。ここで j_χ = E[χ]、G_χ = E[χ ∂_w u]/j_χ(形の項、≈ 1)。
- **ピントの傾きの項は、これで式から消える。**
- 速さを状態自身の W 方向の尺度で測る:L = λ√J_ww。このとき:
  **Θ_χ = α G_χ/(1 + λ√P_χ)、 α = j_χ/j**(なめらかにしても残るピントの割合)
- **段6 の改良。** −E[gH_ww] + 2J_ww を κ₂J_ww(κ₂ = 2 − E[gH_ww]/J_ww)としてまとめ、ε に移さない。T = Θ_χσ√(κ₂/2) とおくと、y についての最小値は T/(1 + T/κ₂)。よって:
  **1 − R ≥ T/(1 + T/κ₂) − ε₂ − D、 ε₂ = (E[χ(E[δ⁴|y]/48 − Var(X_q|y)/4)]/σ² + N)/J_tot**

### 確認
- 全 290 状態 × 6 通りの λ で、(3′)、(4′)、E[gw] ≥ E[gχ]、A_χ ≤ J_ww、√χ のリプシッツ条件がすべて成立した。
- 下限はすべて実際の 1 − R 以下だった。
- χ の作り方は、総当たりで求めた「最大の関数」と一致した。
- 改良した段6 は、乱択 2000 例で成立した。

### 条件つき一様下限(λ = 1 の例)
- 状態の集まりで、α ≥ α₀、G_χ ≥ G₀、κ₂ ≥ κ₀、ε₂ + D ≤ ησ が成り立つとする。Θ₀ = α₀G₀/2、T₀ = Θ₀√(κ₀/2) とおく。
- このとき、その集まりのすべての状態で:
  **1 − R ≥ σ·[T₀/(1 + T₀σ/κ₀) − η]**
- 山頂に集まった 236 状態の値:α₀ = 0.814、G₀ = 0.974、κ₀ = 1.967、η = 0.049。これで **c = 0.344**(主要項)。

## 2. 追加の仮定(成分数・太さ)で一様になるか
- **観測:**
  - α(λ = 1) は、K = 1〜40、太さ 0〜数σ の全状態で 0.768 以上だった。
  - 二本の線分を大きな角度(0.03〜0.6 ラジアン)で交差させた例でも、α(λ = 0.5) は 0.83〜0.99。
  - α が 0 に近づく状態は見つからなかった。
- **しかし証明はできなかった。理由:**
  1. α は「V 方向のピントが、状態自身の W 方向の尺度に比べてどれだけ急に変わるか」で決まる。それを決めるのは成分どうしの交差角と離れ方で、成分の数や太さではない。二成分でも、交差のしかたで w の谷の急さはいくらでも変えられる。
  2. 形の項 G には、H の下限が要る。谷(H が負)があると押さえられず、K を制限しても谷は作れる。
  3. ε₂ は、山頂から遠い広い成分があると大きくなる。「成分の中心は山頂から距離 d 以内」のような位置の仮定なら抑えられるが、K や太さの仮定ではない。
- **言えること:** K = 1(単一ガウス)なら、条件なしで 1 − R ≥ 1 − R\*(σ) = σ − (7/8)σ² + (65/96)σ³ − …(段階H、厳密)。K ≥ 2 で一様な c を得るには、上の三つの量の下限を直接仮定するしかない。

## 3. 論文用のまとめ(修正済みの文面)

**状態ごとの定理。** 振り子(κ = 1)のどの状態についても、次が成り立つ:
1 − R ≥ Θ′σ/(1 + Θ′σ/2) − ε̃ − D
- Θ′ = (|E[w u s_w]|/E[w])·√(J_ww/E[w s_w²])
- ε̃ = (E[w(E[δ⁴|y]/48 − Var(X_q|y)/4)]/σ² + N + E[g H_ww])/J_tot
- w = σ²(H_vv)₊、u = √2(m_q − π)、D は事後 Stein 欠損

証明に使うのは、厳密な恒等式、sin²(x/2) ≥ x²/4 − x⁴/48、W 方向の重みつき Cramér–Rao(Cauchy–Schwarz)、Tweedie からの H ⪯ I/σ²、初等的な最小化だけで、符号の条件はない。

**条件つき一様下限。**
- (a) 状態の集まりで Θ′ ≥ Θ₀ かつ ε̃ + D ≤ ησ ならば、1 − R ≥ [Θ₀/(1 + Θ₀σ/2) − η]σ。
- (b) なめらかにした重み(√χ が W 方向に (λ√J_ww/2)-リプシッツ、0 ≤ χ ≤ w)について α ≥ α₀、G_χ ≥ G₀、κ₂ ≥ κ₀、ε₂ + D ≤ ησ ならば、1 − R ≥ [T₀/(1 + T₀σ/κ₀) − η]σ。ここで T₀ = α₀G₀√(κ₀/2)/(1 + λ)。
- (c) 単一ガウス(K = 1)では条件なしに 1 − R ≥ 1 − R\*(σ) = σ − (7/8)σ² + …。

**観測。** 保存した 290 状態(σ ≤ 10⁻² では 268 状態)で:
- 実際の 1 − R ≥ 0.946σ
- 状態ごとの定理 ≥ 0.898σ(積分の形 ≥ 0.909σ)
- Θ′ ≥ 0.9125
- なめらかにした重み(λ = 1)で α ≥ 0.768
- 山頂に集まった 236 状態で、(b) の下限 ≥ 0.389σ。そこから得た定数は c = 0.344。
- 混合の最良は R\*(σ) を余裕の約 5 % だけ上回る(扇の極限は約 4.8 %)。

**未解決の一歩。** Θ′(あるいは α、G、ε₂)の、状態によらない下限。
- 障害は、ピントの重み σ²H_vv が W 方向にどれだけ速く変わりうるか(log p_Y の三階微分)を、H ⪯ I/σ² だけからは押さえられないこと。
- 成分数や太さの仮定もこれを与えない。
- 交差角や成分の位置についての仮定、あるいはピントの寄せ方を直接扱う変分法的な議論が必要と考えている。
