(ニューラルネットなし・厳密計算のみ。全数値はコードで確認済み:verification/run_all_B.py 34/34 PASS、段階Aの run_all.py も 29/29 PASS のまま)

## 式1の位置づけ(文献確認を受けて)
式1 R = tr(F Sym J̄)/tr F の中心の一歩は、Stein の補題 E[f(X)(X−m)ᵀ] = E[Df]·P である。これはガウス近似フィルタの統計的線形化と同じ一歩である。
したがって式1は、「ガウスの状態では、エントロピー生成が、平均ヤコビ J̄ で線形化した流れのものと一致する」ことを言い直したものと位置づける。新しい結果とは主張しない。

## 分かったこと

### 0. 土台:R を三つに分ける厳密な式(全状態で誤差 < 2×10⁻¹¹)
ぼかしの公式(二階の Tweedie:Cov(X|y) = σ²I − σ⁴H(y)。H = −∇² log p_Y は「目に映る分布の局所的な鋭さ」=局所フィッシャー行列)を使うと、どの状態でも次が成り立つ。

> **R = 法則項 + 共分散項 + D**
> - 法則項 = tr(F · Sym E_ρ[Df]) / tr F:式1を「本当のフィッシャー行列 F」と「データ全体で平均したヤコビ」で使ったもの。必ず λ_ρ 以下になる。
> - 共分散項 = E[tr((H(Y) − F) · Sym E[Df|Y])] / tr F:**「目のピントの鋭さ」と「その場所の引き伸ばし」が場所ごとにどう重なるか**。
> - D = 事後分布のガウスからのずれ(Stein の補題の破れ)。事後分布がガウスなら 0。

- 法則項 + 共分散項 = (f) =「局所フィッシャーで重みづけた引き伸ばし」E[tr(H·Sym E[Df|Y])]/E[tr H]。
- 一つの山では H が一定なので、共分散項 = 0、D = 0、R = 法則項 = 式1。段階Aの結果はこの特別な場合にあたる。
- 確認方法:x 方向の直接積分と有限差分による総当たり計算(Stein も Tweedie も使わない別の方法)で、D = −0.0071 を 4×10⁻⁶ の精度で再現した。

### 1. 測定1:反例の仕組み
基本の形:安定点 q = 0 を中心とする二つの山。山1は細く(引き伸ばし方向 V の幅 0.09)長い(縮み方向 W に 1.9)。山2は幅が山1の n₂/n₁ 倍で、長さ 1.2。σ = 0.1。

- **間隔は要らなかった。** 中心を重ねたまま(δ = 0)でも R/λ_comp = 1.060 になる。反例の本体は「ずれ」ではなく**「幅の違う山の重なり」**である。
- **幅の比が決め手。** δ = 0 で比 1 / 2 / 4.4 / 8 のとき、R/λ_comp = 0.745 / 0.861 / 1.060 / 1.117。
  - 地図(図 stageB_m1_maps 左)では、比 ≳ 2.85 で λ_comp を超えた。
- **ずらす方向で結果が変わる。**
  - 縮み方向 W にずらすと、重なりは残り(δ/σ = 30 でも 0.47)、超えたまま(最小 1.060)。
  - 引き伸ばし方向 V にずらすと、重なりが 0.11 まで減った δ/σ = 12 で 0.977 に落ちる。
- **細長さも要る。** 山1の細長さ l₁/n₁ ≳ 12 で、かつ重なり ≳ 0.34 のときに超えた(地図 中央)。
- **傾きで弱まる。** 山2を回すと、90° で 1.009 まで下がる(δ = 0)。
- **超えるときの内訳**(512 状態中、超えたのは 227。図 右の棒グラフ):
  - 法則項は、どの状態でも λ_ρ 以下(< λ_comp)。
  - **超える分はすべて共分散項から来る**(超えた状態で共分散項 ≥ 0.037)。比 1 では共分散項 0.0006、比 4.4 では 0.095。
  - D は小さい(基本形で −0.0001)。
- 別の分け方:R = A·R_sep + R_switch。
  - A(重なりで失われるフィッシャー情報の分の増幅、A = 1.14〜1.58)が R_sep を押し上げる。
  - 責任度の切り替え項 R_switch(超えた状態ではすべて負)が一部を打ち消す。
- 話し言葉の解釈(推測):重なった中心では、太い山がピントをぼかす。細い山だけが伸びている先端側(q が 0 から離れ、引き伸ばしが強い場所)では、ピントが鋭いまま残る。「ピントの鋭い場所が、引き伸ばしの強い場所に偏る」ので、どの山単独の平均引き伸ばしよりも R が大きくなる。共分散項が正であることは確かめた。しかし「先端側」という場所の特定は、図を描いて確かめてはいない。

### 2. 測定2:余り R − e
厳密に R − e = (f − e) + D。

**(i) 一つの山:余りは閉じた式になり、「曲がり × 窓幅²」で抑えられる**
- 閉じた式:R − e = −E_ρ[cos q]·K_qq·K_qp / tr F、K = S(S+σ²I)⁻¹。1675 ケースで誤差は 4.3×10⁻¹²。
- 上の式から、厳密な上限が出る:|R − e| ≤ σ²·|E_ρ[a″(q)]|。a″ = cos q / 2 は**引き伸ばしの二階微分(曲がりの曲がり)**。実測の比は最大 0.960。
- 効いているのは sin q(一階)ではなく cos q(二階)だった。sin q の寄与は、山の対称性で厳密に消える。
- 符号の規則:sign(R − e) = sign(R·cos q₀)(800/800)。cos q₀ = 0 では余りが厳密に 0(1.5×10⁻¹² 以下)。小さい σ で σ² に比例(傾き約 2)。

**(ii) 二つの山:曲がりだけでは抑えられない**
- 重ならない混合では、比 |f − e| / (σ² E|a″|) は最大 1.02 で、(i) とほぼ同じ。
- 重なると最大 5.8 まで超える。責任度が切り替わることで、窓の中で「事後の引き伸ばし」が急に変わるためと考えられる(推測)。Spearman 相関は cos 版 0.74、sin 版 0.70。
- D(事後分布のガウスからのずれ):
  - 重ならないとほぼ 0(中央値 3×10⁻¹²)。
  - 重なりとの順位相関は 0.89。H が正定値でない領域の質量とは 0.70。
  - σ とともに増える(最大 |D|:σ = 0.03 で 0.0003 → σ = 1 で 0.057。同じ状態での傾きの中央値は 2.3)。
  - 符号の規則はない(正 401 / 負 411)。
  - H がどこでも正定値の状態でも、D は最大 0.012 になる。
- 重なりのある 432 ケースでは、(f) は (e) より R に近い(|R − f| の中央値 0.0020、|R − e| は 0.0048。全 1000 ケース中 885 で f の方が近い)。

**(iii) 「局所的な異方性のばらつき」(ご提案の候補)**
- D とはほぼ無関係だった。固有値比のばらつきとの順位相関は 0.07、V/W 異方性のばらつきとは −0.02。
- 効いていたのは共分散項の方である。V/W 異方性のばらつきと |共分散項| の相関は 0.64(固有値比版では 0.19)。
- つまり**異方性のばらつきは「余り」ではなく「反例の本体」の側に入っている**。式の上でも、共分散項は H − F(局所の鋭さと平均の鋭さの差)そのもので書ける。

## まだ分からないこと
1. **予想1(R ≤ κ)はまだ開いている。** 新しい形では、予想1 ⟺ 共分散項 + D ≤ κ − 法則項。
   - 法則項 ≤ λ_ρ ≤ κ は常に成り立つ。
   - 共分散項は、H が正定値なら tr(H·G) ≤ λmax(G)·tr H なので (f) ≤ κ が言える。ただし H が正定値でない場所(山の谷間)があると、この議論は使えない。
   - D の上限もない。
2. **D の大きさを決める量。** 重なりとは強く連動するが、式としての上限は見つかっていない。σ への依存(傾き 1.5〜4.6 とばらつく)の理由も分からない。
3. 重なった混合で、f − e を抑える量(曲がり以外に、責任度の変化の速さが要るはず)。
4. 「ピントの鋭い場所が引き伸ばしの強い場所に偏る」という解釈が、他の形や他の流れでも成り立つか。
5. 今回はすべて振り子・二成分・2次元。四次の振動子、3成分以上、高次元は未確認。

## 推測(観測が支える範囲に限る)
- R が「どの成分の平均引き伸ばしよりも大きくなる」には、重なり・幅の違い・細長さの三つがそろう必要があるように見える。今回の家族では、比 ≳ 2.85、細長さ ≳ 12、重なり ≳ 0.2〜0.34 だった。家族の外ではまだ確かめていない。
- それでも R の最大は 1 に届かなかった(段階A・Bを通じて最大 0.949)。超えた量も小さい(λ_comp の最大 1.117 倍)。

## 次に測るもの(提案)
1. **予想1が破れるとすれば、H が正定値でない場所(谷間)で共分散項か D が大きくなるとき。** そこを狙った敵対的探索をする(目的関数 = 共分散項 + D − (κ − 法則項)、中心 q = π 付近)。
2. D を「事後分布の混合のずれ」(責任度の分散 × 成分間の平均引き伸ばしの差)と並べ、上限の候補を探す。
3. 共分散項について、H − F と引き伸ばしの空間分布を図にし、「ピントの偏り」の解釈を直接確かめる。
4. 四次の振動子・二重井戸で、三項分解をそのまま回す(式はどの流れでも成り立つ形にしてある)。
