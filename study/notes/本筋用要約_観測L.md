3. **L1(c) 最適な扇の形(推定):**
   - 重みは角度について **sech²(α/0.43)**。ガウス形ではない。

4. **L3 連成振り子(4 次元):最良ガウスの係数に、閉じた式が見つかった。**

   - 「方向の数とともに増える」という予想は、そのままの形では**否定された**。
     - 運動量だけの方向はただ(コストゼロ)。
     - 増えるのは連成 ε があるときだけで、小さな ε では 1 + √ε。
5. **L2 ねじれの流れ:曲げた扇は 0.5 を下回った(0.4894σ)。ただし、段階I の「曲げた針 0.509 ≈ 予言 1/2」には訂正が要る。**

   - 0.509 の状態そのものは正しい状態なので、「0.509 に達する」は正しい。
   - 曲げた扇も同じで、0.4894 は 12 本の多角形の値。48 本にすると 0.509 になる。

## 2. L1(b):焦点の傾きの上界の候補

### 測った比(317 状態:段階A〜K の 290 と、段階L の 27)

| 比 | 全状態(σ ≤ 10⁻²)の最大 | 最適に近い状態(gap ≤ 1.2σ、142 状態)の最大 | gap との順位相関(近い状態) |

- **一般に成り立つこと(証明):** Λ/j = geo + slope = geo·(1 − ρ)、かつ w ≤ 1 から J_ww ≥ E[w s_w²]。よって **Θ′ ≥ geo·(1 − ρ)**。全 317 状態で破れはなかった。
- **条件つきの一様定数:**
  - クラス「geo ≥ G₀、ρ ≤ ρ₀、ε̃ + D ≤ ησ」では、1 − R ≥ (G₀(1 − ρ₀)/(1 + …) − η)σ。

  - Cauchy–Schwarz で、段階J の鎖は Θ′ の代わりに Θ_ν = geo·√J_ww/(√E[ws²] + √(νJ_ww)) ≥ geo/(1 + √ν) でも成り立つ。ν に一様な上限があれば、一様な c が出る。

  - 理由:ピント w が谷の縁で 0 まで直線的に落ちる所では、(∂w)²/w の積分が対数的に発散する。
  - 段階K でピントをなめらかにした(χ)のは、まさにこれを避けるためだった、と確認できた。

### 3 次キュムラント(∂_w H_vv)から証明できるか

**判定:3 次キュムラントだけからは「見込みが薄い」。二択の形なら「方針がある」。**

- **見込みが薄い理由**
  1. ρ 自体が一様に有界でない(ρ = 90 の実例)。だから「ρ ≤ ρ₀ をすべての状態で示す」形の証明はありえない。
  2. ∂_w w = −κ₃(vvw)/σ⁴(事後分布の 3 次キュムラント)。H ⪯ I/σ² は w ≤ 1 を与えるが、κ₃ の上限は与えない。谷では事後分布が W 方向に二つに割れ、κ₃ は σ³ より大きくなりうる。
  3. ν(∂_w √w の 2 乗の平均)は、w が 0 に落ちる所で発散する。3 次キュムラントの 2 乗平均で押さえる道も、そのままでは閉じない。
- **方針がある理由(二択)**
  - ρ が大きい状態は、どれもギャップが大きかった。
    - ρ > 0.3 の状態(2 個)のギャップは、最小でも 1.92σ。
    - ρ > 0.5 の状態は 1105σ。
  - そこで、次の二択を示せばよい。
    - (i) ρ ≤ 1/2 なら、Θ′ ≥ geo/2 から c を出す。
    - (ii) ρ > 1/2 なら、別の評価(法則項の κ − λ_ρ、または段階I の寄せの上限)でギャップが大きいことを示す。
  - (ii) に必要なのは、「ρ が大きい ⟹ ピントの重み j が山頂から離れた所に乗っている ⟹ 法則項の不足 κ − λ_ρ が大きい」という関係である。これは 3 次キュムラントではなく、「ピントの位置」と「伸びの不足」の関係なので、段階J の (1 − f) の恒等式の中で扱える見込みがある。
  - まだ式にはなっていない。

## 4. L3:連成振り子 H = (p₁² + p₂²)/2 − cos q₁ − cos q₂ − ε cos(q₁ − q₂)

### 法則 1 の 4 次元での照合
- 法則 1(R = tr(F Sym J̄)/tr F)を、2 通りの独立な計算と比べた。
  - 4 次元 Gauss–Hermite 格子(18⁴ 点)。Stein の補題を使わず、事後平均から直接計算する。
  - モンテカルロ(4×10⁶ 点)。
- ランダムな 9 状態(ε = 0、0.1、0.3)で、Gauss–Hermite との差は 10⁻¹⁰ 未満。モンテカルロとは、すべて標準誤差の 2.4 倍以内で一致した。

### κ と、それを取る点
- **κ(ε) = (1 + ε + √(1 + ε²))/2**。点 (q₁, q₂) = (π, 0)(と (0, π))で取る。
  - (π, 0) での固有値の計算は厳密。それが全体の最大であることは、トーラス上の 1441² 格子で確かめた(10⁻¹² 以内)。
  - ε = 0 のときは κ = 1 で、q₁ = π または q₂ = π の線の上ならどこでも取る。
- 値は、ε = 0.1 で 1.0525、0.3 で 1.1720、1 で 1.7071。

- **予想「方向の数とともに係数が増える」の判定:そのままの形では否定。**
  - 増えた 3 方向のうち、運動量だけの方向 p⁻ はコストゼロ(伸び M は q だけで決まるので、p⁻ に広げても伸びは減らない)。
  - 位置の方向 q⁻ のコストは 2√(B₂₂κ)。B₂₂ は、「q⁻ に広げると最大の伸びがどれだけ減るか」を表し、連成 ε に比例する。
  - ε = 0(独立な二つの振り子)では、係数は 1 自由度と同じ 1。
  - **正しい言い方:係数は「方向の数」ではなく、「最大の伸びが、位置空間のほかの方向への広がりにどれだけ敏感か」で増える。**
  - 一般化の候補(推定):n 自由度では、C = diag(2κ, κ, …, κ)(位置の方向ごとに κ)と、(n×n − 運動量方向)の B で、2 tr[(B^½CB^½)^½]。

### 訂正:段階I の「曲げた針 0.509 ≈ 予言 1/2」
- 段階I の曲げた針は、n 本の短い直線片(ガウス)を円弧に沿って並べたものだった。
- 同じ形で n だけ変えると、値が上がり続ける(図 stageL_arc_pieces):

| n(直線片の数) | 24 | 48 | 64 | 128 | 192 | 384 |
|---|---|---|---|---|---|---|
| 段階I の形(24 片で最適化) | 0.5027 | 0.5089 | 0.5138 | 0.5313 | 0.5452 | 0.5688 |
| 64 片で最適化し直した形 | — | — | 0.5031 | 0.5091 | 0.5160 | 0.5339 |

- これは数値誤差ではない。σ = 10⁻² で、n = 24 と 96 を核の直接和でも計算し、5×10⁻⁵ 以内で一致した(0.4959 と 0.5088)。
  - 段階I の注記「96 片で g\* が少し下がる」は、この現象の一部だった。
- 太さを 5 倍にしても値はほとんど変わらない(0.5089 → 0.5098)。効いているのは太さではない。
  - 直線片の端は、円弧からはみ出す。片が長いほど、はみ出しは大きい。こうして片の端が「接線の小さな扇」を作っている。片が短くなる(n が増える)と、この扇の効果が消える。これが値の上がる理由と考えている(解釈。推定)。
- **何が正しく、何が言い過ぎか:**
  - 正しい:0.503〜0.509σ の状態は存在する(多角形の針)。ガウスの √3/2 = 0.866 から 40% 下がる、も正しい。
  - 言い過ぎ:「なめらかに曲げた針が 1/2(β_eff = 1/8 の予言)に一致する」。なめらかな曲線の値は、まだ決まっていない。384 片で 0.534 で、まだ上がっている。予言 1/2 は、なめらかな針については確かめられていない。
  - 曲率が回転の速さ 1/√2 に一致すること(0.712)は、64 片で最適化し直しても変わらなかった。
